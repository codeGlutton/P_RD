상세한 설명

전투 중 특정 시점(타격 전/후, 피격 전/후 등)에 발동하는 패시브의 베이스. 액티브 스킬과 달리 플레이어가 직접 발동하지 않고, 타이밍 태그에 맞춰서 호출됨.

계산할 때는 내부 상태를 바꾸지 않으며 적용 함수가 호출될 때만 내부 상태를 변경.

상태 보유 여부
스택 카운터 같은 내부 상태가 필요한 패시브만 mState를 사용함. 상태가 없는 패시브는 mState를 비워두고 PassiveState를 무시하면 됨.

IN const FPassiveActivateContext &  Ctx,

드라이버는 타이밍태그마다 패시브의 처리 내용을 모른 채 이 함수를 호출.

진입 시 상태 작업본을 준비(커밋본 복사 또는 InitializeState)한 뒤, 들어온 타이밍이

  • 카운터 리셋 시점(mCounterResetTimingTag)이면 OnCounterReset.
  • 캡처 시점(mCaptureTimingTag)이면 OnCapture.
  • 발동 시점(mActivateTimingTag)이면 OnActivate.
  • 해제 시점(mDeactivateTimingTag)이면 DeactivatePassive(해제=제거). 같은 태그가 여러 시점에 걸릴 수 있으므로 위 순서대로 전부 처리.

라우팅이 고정돼 있으므로 일반함수로 두고, 파생클래스에서는 시점별 가상 함수를 구현.

매개변수
TimingTag타이밍 태그 (발동/해제 시점 분기에 사용)
Ctx소유자/대상 및 스냅샷
PassiveState[in,out] 패시브 내부 상태 (드라이버가 받아서 CommitPassive 함수 호출에 사용)

◆ DeactivatePassive()

void UTacticalPassive::DeactivatePassive ( )

NotifyPassive에서 저장해 둔 핸들로 이펙트를 활성 집합에서 제거한다. 상태이상은 이 패시브가 넣은 스택 수만 제거해 다른 출처의 스택은 남김. 되돌리는 수치 계산은 없으며, 제거 후 TAS가 base에서 재계산해 기여가 빠진 값이 된다. 조건을 따지지 않고 즉시 내린다(예: 장비 장착 해제).
