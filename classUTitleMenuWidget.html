UTitleMenuWidget::UTitleMenuWidget ( const FObjectInitializer &  ObjectInitializer = FObjectInitializer::Get())

타이틀 메인 메뉴 UI 위젯.

방 진입 직후 보이는 메인 화면으로, START/CONTINUE/SETTING 버튼과 캐릭터 선택 화면 전환, 배경 영상(UMediaTexture) 표시를 담당한다. 화면 전환(메인↔캐릭터)과 하위 위젯의 "뒤로 가기" 요청 처리 책임이 이 클래스에 모여 있다.

생성자. 버튼/타이틀 텍스트의 기본 문구와 기본 Visibility를 설정한다.
