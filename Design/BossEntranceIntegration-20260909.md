# 보스방 입장 연출 누락 수정

입장 연출은 승인한 시연 영상만 존재했고 이전 PR #670은 처치 만화만 연결했다. 이번 변경은 ACombatGameMode::BeginRoom에서 미클리어 보스방에 한해 입장 영상을 먼저 재생하고, 완료 뒤 BeginCombat을 한 번만 호출한다. 일반 방은 바로 전투를 시작한다.

- 레시: 연속 컷 → 급제동(3초).
- 골렘: 갑옷 훑기 → 상단 얼굴 컷 → 자세 펼치기(10.3초).
- 네크로맨서: 바닥에서 퍼지는 빛과 웅장한 음악(14초).

UCinematicWidget에 선택적인 미디어 음성 출력을 추가했다. 기존 타이틀 영상의 기본 음성 설정은 바꾸지 않는다. 보스방 BGM은 재생 중 일시 정지하고 종료 뒤 복귀한다. 터치/키/뒤로가기는 넘기지 않는다. 영상 누락은 즉시 전투로 진행하며 미디어 오류/오픈 지연/종료 이벤트 누락에는 폴백이 있다. 월드 종료 시 콜백을 취소해 이전 월드에서 전투가 시작되지 않게 한다.

## 배포

SVN r429:
- OutSideAsset/AICreation/UI/StageVictory/BossEntrance/BossEntrance1~3.mp4
- SourceArt/UI/BossEntrance: 원화·음원·편집 기록·효과음 출처와 해시.

게임 MP4 3개는 승인 시연과 동일한 H.264/AAC 파일이다. Build.cs 및 빌드 영수증에서 세 파일의 NonUFS 스테이징을 확인했다. 보스 처치 연출 및 파티 엔딩 v5는 별도이며 이번 변경으로 파티 엔딩이 연결되지는 않는다.

## 검증

Win64 Development Editor 빌드 통과. P_RD.UI.Boss 자동화 4개(기존 처치 연출 3개 + 입장 파일/분기 1개) 통과. 별도 게임 프로세스에서 RD.BossEntrance.Preview 0 verify로 세 영상이 순서대로 열리고 각 길이 후 완료되는 것을 확인했다. 각 영상의 오디오 트랙 1개/출력 컴포넌트 활성 로그, 뷰포트 캡처를 확인했다. 실제 보스방 진입부터 첫 턴까지의 전체 플레이와 모바일 패키징/기기 음향 검증은 아직 하지 않았다.

미리보기 명령은 보상이나 저장을 변경하지 않는다. 검증 실행 중 게임 모듈 초기화에서 기존의 위치 정보 없는 Condition failed 로그가 4회 발생했으며, 이후 영상 3개는 모두 재생·종료됐다. 자동화 테스트 보고서는 실패 0개다.
