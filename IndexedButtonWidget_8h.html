 여러 개 생성되는 버튼이 자기 번호를 같이 알려주게 만든 UButton입니다. 더 자세히 ...
 

함수

 DECLARE_DYNAMIC_MULTICAST_DELEGATE_OneParam (FIndexedButtonWidgetEvent, int32, ButtonIndex)
 눌린 버튼 번호를 보내는 이벤트입니다.
 

상세한 설명

스킬 목록이나 주사위 목록처럼 버튼을 여러 개 만들면, 어떤 버튼이 눌렸는지 번호가 필요합니다. 기본 UButton은 번호를 알려주지 않으므로, 이 클래스가 클릭 이벤트에 번호를 붙여서 다시 알려줍니다.

IndexedButtonWidget.h 파일에서 정의되었습니다.
