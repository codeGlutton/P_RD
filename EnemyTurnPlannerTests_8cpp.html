상세한 설명

이동성향 3종(MoveClose/HoldRange/MoveAway) × 조준 가능/불가 2가지 엮어서 6가지 케이스 테스트. 추가로 직사 스킬 일직선 후퇴 시 자기 차폐로 제자리 사격하던 회귀 케이스(Case1-3), 다른 몹에 막혀 조준 불가일 때 우회 접근하지 않고 제자리에 서던 회귀 케이스(Case3-3), 다중 스킬 우선순위: 동순위 랜덤(Case4-1), 우선순위 높은 슬롯(Case4-2), 최우선 쿨다운이면 차순위(Case4-3), 최우선이 사거리 밖이면 스킬 유지하고 접근(Case4-4). 다중 플레이어 대응: 최근접 타겟 선택(Case5-1), 시전 가능 타겟 우선(Case5-2), 균형 후퇴(Case5-3), 최근접 접근 폴백(Case5-4). 속박: 제자리 시전(Case6-1), 사거리 밖(Case6-2), 비용 있는 스킬 시전 회귀(Case6-3). Single 조준 스킬: 영향 범위로 타격 판정(Case7-1), 자기 차폐 회귀(Case7-2), 접근 폴백(Case7-3). 자기 버프: 버프 우선순위 낮으면 공격 확정(Case8-1), 버프 우선순위 높으면 비용 떼고 성향 이동 후 버프(Case8-2), 버프만 보유 시 성향 이동(Case8-3), 공격 확정 후 사거리 밖이면 버프로 안 바꾸고 접근(Case8-4), 공격 확정 후 비용 부족이면 버프 없이 선점이동(Case8-5).

케이스 레이블: CaseX-Y X = 이동성향 (1:원거리/MoveAway, 2:등거리/HoldRange, 3:근거리/MoveClose) Y = 조준 여부 (1:가능, 2:불가) 조준 불가는 "이동 후에도 조준범위 밖"인 경우.

Case1-1: 원거리(MoveAway) / 조준 가능 -> 최대조준거리로 이동 후 스킬 사용 맵 (8x2): E(2,1) P(1,0) -> 최대 원거리 타격가능지점인 (4,1)로 이동

Case1-2: 원거리(MoveAway) / 이동 후에도 조준 불가능 -> 플레이어에게 최대한 접근 맵 (10x3): E(0,1) P(9,1) -> 이동포인트를 최대한 사용해서 (4,1)로 접근

Case1-3: 원거리(MoveAway) / 직사(Cross) / 플레이어와 일직선 -> 후퇴 타일의 시야가 자기 자신에게 막히면 안 됨 (제자리 사격 회귀 방지) 맵 (8x1): E(1,0) P(0,0) -> 사거리 최대 지점인 (4,0)으로 후퇴 후 스킬 사용

Case2-1: 등거리(HoldRange) / 조준 가능 -> 현재위치에서 조준되므로 이동없음 + 스킬사용 맵 (6x3): E(2,1) P(3,1) -> 이동커맨드 없고, 바로 스킬 사용

Case2-2: 등거리(HoldRange) / 이동 후에도 조준 불가능 -> 플레이어에게 최대한 접근 맵과 결과는 Case1-2와 동일

Case3-1: 근거리(MoveClose) / 조준 가능 -> 현재위치에서 조준되므로 이동없음 + 스킬사용 맵 (6x3): E(2,1) P(3,1) -> 이동커맨드 없고, 바로 스킬 사용

Case3-2: 근거리(MoveClose) / 이동 후에도 조준 불가능 -> 플레이어에게 최대한 접근 맵과 결과는 Case1-2와 동일

Case3-3: 근거리(MoveClose) / 다른 몹이 앞을 막아 조준 불가 (제자리 멈춤 회귀 방지) -> 맨해튼 거리로는 가까워지는 칸이 없어도, 우회 경로로 실제 가까워지는 칸으로 이동해야 함 맵 (8x2): P(0,1) M(1,1) E(2,1), 이동력 2, 직사(Cross) 사거리 4 -> 어느 도달 칸에서도 조준 불가 (열 정렬 칸은 이동력 밖, 행 정렬 칸은 M에 차폐) -> 경로 거리 기준 최선인 (1,0)으로 우회 접근, 스킬 없음

Case4-1: 다중 스킬 / 동순위 / 둘 다 조준 가능 -> 동순위는 랜덤 선택되어 시전 (어느 쪽이든 유효 슬롯이어야 함) 맵 (6x3): E(2,1) P(3,1), 슬롯0 사거리1 + 슬롯1 사거리2 (둘 다 제자리에서 조준 가능), 둘 다 Normal -> 이동커맨드 없고, 스킬 인덱스는 0 또는 1

Case4-2: 다중 스킬 / 슬롯1 우선순위 높음 -> 랜덤 없이 슬롯1 확정 맵과 배치는 Case4-1과 동일, 슬롯1 Highest

Case4-3: 다중 스킬 / 슬롯1 우선순위 높지만 쿨다운 -> 쿨다운 슬롯은 건너뛰고 차순위 슬롯0 확정 맵과 배치는 Case4-1과 동일, 슬롯1 Highest + 쿨다운

Case4-4: 다중 스킬 / 최우선 슬롯1은 사거리 밖, 슬롯0은 제자리에서 시전 가능 -> 스킬을 바꾸지 않고 슬롯1 기준으로 접근만 (예상 스킬과 실제 스킬 일치 검증) 맵 (10x3): E(0,1) P(4,1), 근접 성향, AP 2, 슬롯0 사거리5 + 슬롯1 사거리1(Highest) -> 슬롯1 조준 가능 타일은 이동력 밖 -> 시전 없이 (2,1)로 접근

Case5-1: 다중 플레이어 / 둘 다 시전 가능 -> 최근접 타겟을 선택해서 시전 맵 (6x3): E(2,1) P1(3,1) P2(0,1), 등거리 성향, 이동력 3, 사거리 1 -> P1(거리1)이 P2(거리2)보다 가까우므로 제자리에서 P1에게 시전

Case5-2: 다중 플레이어 / 최근접은 차단유닛에 막혀 시전 불가 -> 시전 가능한 먼 타겟을 선택 (타겟 우선 구조 검증) 맵 (7x1): P1(0,0) M(1,0) E(2,0) P2(5,0), 근접 성향, 이동력 2, 사거리 1 -> P1은 인접 칸이 M에 막혀 시전/조준 모두 불가 -> P2에게 (4,0)으로 이동 후 시전

Case5-3: 다중 플레이어 / 원거리(MoveAway) 성향의 균형 후퇴 -> 타겟에게서 멀어지되 다른 플레이어 옆으로 가면 안 됨 (최근접 거리 최대화 검증) 맵 (7x1): P1(0,0) E(2,0) P2(6,0), 이동력 2, 사거리 3 -> 타겟은 최근접 P1(거리2). 시전 가능 타일 (1,0)~(3,0) 중 두 플레이어 모두에게서 가장 먼 정중앙 (3,0) 선택

Case5-4: 다중 플레이어 / 전원 조준 불가 -> 최근접 플레이어에게 접근 맵 (10x3): P2(0,1) E(4,1) P1(9,1), 근접 성향, 이동력 2, 사거리 1 -> 어느 타일에서도 조준 불가 -> 최근접 P2(거리4) 쪽 (2,1)로 접근, 시전 없음

Case6-1: 속박 / 제자리 조준 가능 -> 이동커맨드 없이 제자리에서 시전만 맵 (8x2): E(2,1) P(1,0), 원거리 성향이라 평소라면 물러났을 상황

Case6-2: 속박 / 사거리 밖 -> 접근도 시전도 못 하고 턴 종료만 맵 (8x2): E(6,1) P(0,0), 근접 성향 + 사거리 1이라 평소라면 접근했을 상황

Case6-3: 속박 / 비용 있는 스킬 / 제자리 조준 가능 (이동 예산 0이 시전 예산까지 0으로 만들던 회귀 방지) -> 이동은 못 해도 AP 6으로 비용 2 스킬은 시전 가능해야 함 맵 (6x3): E(2,1) P(3,1), 등거리 성향, AP 6, 스킬 비용 2

Case7-1: Single 조준 / 영향 범위 Cross(1) / 플레이어 인접 -> 조준 타일은 자기 칸이지만 영향 범위에 플레이어가 들어오므로 제자리 시전 -> 시전 커맨드의 조준 타일은 플레이어 칸이 아니라 자기 칸이어야 함 맵 (6x3): E(2,1) P(3,1), 등거리 성향, 이동력 3

Case7-2: Single 조준 / 영향 범위 Cross(2) / 출발 칸 너머의 플레이어 (자기 차폐 회귀 방지) -> 한 칸 물러난 (2,0)에서 왼쪽으로 뻗는 영향 범위가 자기 출발 칸 (1,0)에 막히면 안 됨 맵 (8x1): P(0,0) E(1,0), 원거리 성향, 이동력 6 -> 시전 가능 타일은 (1,0)과 (2,0). 최근접 거리 최대인 (2,0)으로 이동 후 자기 칸 조준 시전

Case7-3: Single 조준 / 영향 범위 Cross(1) / 이동해도 닿지 않음 -> 플레이어에게 최대한 접근, 시전 없음 맵 (10x3): E(0,1) P(9,1), 근접 성향, 이동력 4

Case8-1: 공격 가능 + 자기 버프 보유 / 버프 우선순위 낮음 -> 우선순위 높은 공격 확정, 버프는 시전하지 않음 맵 (6x3): E(2,1) P(3,1), 등거리 성향, AP 3, 공격 사거리 1, 버프 비용 1 (슬롯 2, Lowest)

Case8-2: 버프 우선순위 높음 / 이동 예산이 남는 경우 -> 버프 확정 후 시전 비용을 먼저 떼고, 남는 예산으로 이동 성향대로 이동한 뒤 버프 시전 맵 (10x3): E(0,1) P(3,1), 근접 성향, AP 4, 공격 사거리 1, 공격 비용 3, 버프 비용 2 (슬롯 2, Highest) -> 이동 예산 4-2 = 2 → 근접 성향으로 (2,1)까지 이동, 거기서 버프 (조준 타일 = 목적지)

Case8-4: 공격 확정 / 사거리 밖 / 버프 우선순위 낮음 -> 버프로 바꾸지 않고 행동력 전부로 접근 맵 (10x3): E(0,1) P(9,1), 근접 성향, AP 3, 공격 사거리 1, 버프 비용 3 (슬롯 2, Lowest) -> (3,1)까지 접근, 버프 없음

Case8-5: 공격 확정 / 이동하면 조준은 되지만 시전 비용이 부족 / 버프 우선순위 낮음 -> 남는 AP로 버프하지 않고, 다음 턴을 노려 조준 가능 타일로 선점이동만 맵 (10x3): E(0,1) P(3,1), 근접 성향, AP 4, 공격 사거리 1, 공격 비용 3, 버프 비용 2 (슬롯 2, Lowest) -> 공격은 이동2 + 시전3 = 5 > 4 로 불가 → (2,1)로 선점이동, 시전 없음

Case8-3: 버프만 보유 (공격 스킬 없음) + 원거리 성향 -> 접근 폴백이 아니라 이동 성향대로 멀어진 뒤 버프 시전 맵 (8x1): P(0,0) E(2,0), 원거리 성향, AP 4, 버프 비용 1 -> 이동 예산 3 → 최근접 거리 최대인 (5,0)으로 후퇴, 거기서 버프
