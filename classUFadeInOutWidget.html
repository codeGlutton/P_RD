상세한 설명

WBP_FadeInOut이 없거나 애니메이션이 아직 비어 있어도 기본 검은 패널로 동작하게 하여 전환 API 검증과 모바일 빌드 확인을 먼저 진행할 수 있게 한다.

왜 native fallback을 두는가: WBP 작업이 늦어지거나 패키징에서 위젯 바인딩이 비어 있어도 전환 순서 자체는 검증할 수 있어야 한다.
