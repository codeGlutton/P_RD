상세한 설명

GAS 폐기에 따라 엔진 유틸리티에 있던 "연산별 항등값/스택 크기 계산" 로직을 ETacticalModOp 기준으로 재구현한다(구현은 TacticalEffectType.cpp). 연산을 "합산계열(항등값 0)"과 "곱셈계열(항등값 1)"로 나눠 다루는 것이 핵심이다.

스택(중첩) 수에 따라 모디파이어 크기를 보정해 반환한다.

항등값을 기준으로 (계산값 - 항등값)을 StackCount만큼 반영한다.

  • 합산/일반 배율계열: 항등값 + (BaseComputedMagnitude - 항등값) * StackCount 형태의 선형 누적.
  • MultiplyCompound: 선형이 아니라 거듭제곱 — base^StackCount 로 복리처럼 누적된다.
    매개변수
    BaseComputedMagnitude스택 1개 기준으로 계산된 모디파이어 크기.
    StackCount현재 스택(중첩) 개수.
    ModOp연산 종류(항등값/누적 방식 결정).
    반환값
    스택이 반영된 최종 모디파이어 크기.
    1스택 기준 크기(BaseComputedMagnitude)를 StackCount 만큼 적용했을 때의 합성 크기를 구한다. 핵심 아이디어: 연산의 "항등값(bias)"을 기준으로 한 "순수 증분"만 스택 수에 비례시키고, 마지막에 항등값을 복원한다. 예) MultiplyAdditive(항등 1.0)에서 1스택이 1.2배라면 증분은 0.2. 3스택이면 (1.2-1)*3 + 1 = 1.6배. → 합산식 분기. 예) MultiplyCompound(거듭제곱 곱)는 증분을 더하는 대신 거듭제곱한다. 1스택이 1.2배라면 3스택은 1.2^3. → Pow 분기.

StackCount적용 스택 수(아래에서 0 미만으로 떨어지지 않게 클램프).
ModOp연산 종류(ETacticalModOp). 분기 기준.
반환값
스택이 반영된 최종 모디파이어 크기.

◆ GetModifierBiasByModifierOp()

float TacticalEffectUtilities::GetModifierBiasByModifierOp ( ETacticalModOp::Type  ModOp)

연산 종류별 "항등값(bias)"을 반환한다.

항등값이란 "그 연산에 적용해도 결과를 바꾸지 않는 값"이다.

  • 합산계열(AddBase/AddFinal): 0 (x + 0 = x)
  • 곱셈계열(MultiplyAdditive/DivideAdditive/MultiplyCompound): 1 (x * 1 = x) 모디파이어가 없을 때의 기준값/스택 보정의 베이스로 사용된다.
    매개변수
    ModOp항등값을 구할 연산 종류.
    반환값
    해당 연산의 항등값(합산계열 0, 곱셈계열 1).
    항등값이란 해당 연산에서 "효과 없음"을 뜻하는 기준값이다.

곱셈 계열(MultiplyAdditive, ...)은 1.0 (1을 곱하면 변화 없음)

  • 합산 계열(AddBase, Override, ...)은 0.0 (0을 더하면 변화 없음) 스택 크기 계산(ComputeStackedModifierMagnitude)에서 "순수 증분"만 스택만큼 키우기 위해, 먼저 이 항등값을 빼고 연산 후 다시 더하는 용도로 쓰인다.
매개변수
ModOp연산 종류(ETacticalModOp). 정수값이 곧 배열 인덱스다.
반환값
해당 연산의 항등값(곱셈계열=1.f, 합산계열=0.f).
