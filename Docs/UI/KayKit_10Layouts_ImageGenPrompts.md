# KayKit 톤 전투 HUD 10안 — Codex ImageGen 프롬프트 (마감 목표용)

> 목적이 지난번과 다르다. 지난번 10안 프롬프트는 **배치를 정하려고** 뽑았다.
> 배치는 이미 정해졌고 WBP 열 개가 돌아간다. 이번 열 장은 **마감 목표**다 —
> "이 정도로 다듬어지면 된다"를 눈으로 합의하기 위한 것.
>
> 그래서 제약이 하나 늘었다. **지금 있는 부품으로 만들 수 있는 그림이어야 한다.**
> 만들 수 없는 그림을 받으면 그림에 코드를 맞추게 되고, 그게 지난번에 모서리
> 비율 0.312253이 나온 경위다.

## 1안 — 클래식 CRPG

```
[배치]
화면을 상단 띠 / 전장 / 하단 띠 세 층으로 나눈다.

상단 왼쪽: ROUND 1 패널 (양피지)
상단 중앙: 턴 순서를 원형 초상화 5개로 가로 배열. 각 초상화가 작은
          사각 패널 안에 금속 링으로 들어가 있다. 현재 차례인 기사 패널만
          금색 띠로 강조
상단 오른쪽: 목표 패널 (양피지, 깃발 아이콘 + 텍스트)

하단 왼쪽: 아군 3명 카드를 가로로. 나무 갈색 패널. 기사 카드가 한 단계
          밝고 금색 띠로 강조. 각 카드에 원형 초상화, 이름, HP 바,
          AP 보석 4개(3개 점등), 중독 2턴 표시
하단 중앙: 명령 카드 6장 가로 배열. 푸른 석재 패널. 세로로 긴 직사각형.
          위쪽에 회화 아이콘, 아래쪽에 이름·피해량·쿨타임,
          우상단 둥근 배지에 AP 비용.
          방패 강타는 금색 띠로 강조, 돌파 베기는 어둡게 덮이고 "3턴"
하단 오른쪽: 적 정보 패널(붉은 석재). 그 아래 턴 종료 버튼(주황 나무)

가장 보편적이고 안전한 구성. 정보 밀도가 높다.
```

## 2안 — 좌측 세로 파티

```
[배치]
아군 3명을 화면 왼쪽 가장자리에 세로로 쌓는다. 각 유닛은 가로로 긴 나무
패널이고 초상화 + 이름 + HP 바 + AP 보석이 한 줄에 들어간다.
기사 띠만 오른쪽으로 더 길게 튀어나오고 금색 띠로 강조.

하단은 전체 폭을 명령 레일이 차지한다. 카드 6장이 화면 하단 중앙에 크게
배열되고 카드 하나하나가 1안보다 크다.

상단은 최소화: 왼쪽에 ROUND 1, 중앙에 턴 순서 초상화 줄, 오른쪽에 목표.
적 정보는 화면 오른쪽 가장자리에 세로로 긴 붉은 석재 패널로 붙는다.

전장 중앙이 넓게 비어 아이소메트릭 그리드가 잘 보인다.
```

## 3안 — 활성 유닛 집중

```
[배치]
지금 차례인 기사만 크게 보여준다. 화면 왼쪽 아래에 기사의 큰 나무 패널이
있고, 그 안에 큰 원형 초상화·이름·HP 바·AP 보석 4개·중독 2턴이 넉넉하게
들어간다.

나머지 두 명(궁수, 마법사)은 그 패널 위쪽에 작은 가로 칩으로만 표시된다.
칩에는 원형 초상화와 얇은 HP 바만.

하단 중앙~오른쪽에 명령 카드 6장.
상단은 턴 순서와 목표만.
적 정보는 오른쪽 아래.

"지금 이 유닛의 차례"라는 것이 가장 강하게 읽히는 구성.
```

## 4안 — 방사형 컨텍스트 메뉴

```
[배치]
HUD를 극단적으로 줄이고, 명령을 전장 위 기사 주변에 원형으로 띄운다.

전장 중앙 부근의 기사 캐릭터 주위로 명령 아이콘 6개가 정육각형 배치로
펼쳐져 있다. 각 아이콘은 작은 사각 석재 패널이고 우상단에 AP 비용 배지.
쿨타임 중인 돌파 베기는 어둡게 눌리고 "3턴"이 겹쳐 보인다.
원의 중심에는 기사의 남은 AP가 큰 숫자 "3/4"로 떠 있다.

화면 가장자리는 비운다:
- 상단 왼쪽 ROUND 1, 상단 중앙 턴 순서, 상단 오른쪽 목표
- 하단 왼쪽에 아군 3명의 작은 가로 칩 (초상화 + HP 바만)
- 하단 오른쪽에 턴 종료 버튼

적 정보는 화면 오른쪽 위에 작은 붉은 패널로.

전장 가시성이 가장 좋고, 조작이 캐릭터 근처에서 일어난다.
```

## 5안 — 하단 통합 바

```
[배치]
화면 하단에 두꺼운 가로 바 하나를 두고 거기에 모든 조작을 담는다.
바 전체가 하나의 나무 테두리로 감싸여 통일감을 준다.

바 왼쪽 1/3: 아군 3명이 세로로 얇게 쌓인 칩 목록. 각 줄에 초상화·HP 바.
바 중앙 2/3: 명령 카드 6장 가로 배열.
바 오른쪽 끝: 턴 종료 버튼.

상단에는 ROUND 1과 턴 순서만 얇게. 목표는 오른쪽 위에 작게.
적 정보는 화면 중앙 오른쪽에 떠오르는 붉은 패널로.

화면 위쪽 2/3이 완전히 비어 전장이 크게 보인다.
```

## 6안 — 좌우 대칭 (아군 좌 / 적 우)

```
[배치]
화면을 좌우로 나눠 정보를 대칭으로 배치한다.

왼쪽 세로 열: 아군 3명 나무 카드. 위에서부터 기사(차례, 크게)·궁수·마법사.
             각각 원형 초상화·이름·HP 바·AP 보석.
오른쪽 세로 열: 적 정보. 세로로 긴 붉은 석재 패널에 독수리의 큰 원형
             초상화·HP 바·방어·예상 피해.

하단 중앙: 명령 카드 6장만 가로로. 좌우 열 사이 폭에 맞춘다.
상단 중앙: 턴 순서 초상화 줄. 왼쪽 위 ROUND 1, 오른쪽 위 목표.

아군과 적이 화면에서 마주 보는 구조라 전투 상황이 직관적으로 읽힌다.
```

## 7안 — 카드 핸드 (덱빌더 스타일)

```
[배치]
명령을 손에 든 카드처럼 표현한다.

화면 하단 중앙에 명령 카드 6장이 부채꼴로 살짝 겹쳐 펼쳐져 있다.
카드는 세로로 길고 아래로 갈수록 화면 밖으로 살짝 잘린다. 가운데 카드가
가장 높고 바깥으로 갈수록 낮아지며 조금씩 기울어져 있다.
방패 강타 카드는 위로 떠올라 금색 띠로 강조, 돌파 베기는 어둡게 눌림.

아군 3명은 화면 왼쪽 아래에 작은 세로 나무 카드로.
상단에 ROUND 1·턴 순서·목표. 적 정보는 오른쪽 아래.

카드는 모두 같은 모양의 사각 패널이다. 카드마다 테두리 모양이 다르면 안 된다.

스킬 선택이 가장 즐겁게 읽히는 구성.
```

## 8안 — 미니멀 / 전장 우선

```
[배치]
HUD를 최소한으로 줄인다. 상시 보이는 것은 다음뿐이다.

- 화면 왼쪽 아래: 기사의 가로 칩 하나. 원형 초상화 + HP 바 + AP 보석 4개
- 화면 하단 중앙: 명령 6칸을 아이콘만. 작은 정사각 석재 패널에 아이콘과
  우상단 AP 배지만. 이름·피해량 없음.
  쿨타임 중인 것은 어둡게 + 남은 턴수
- 화면 오른쪽 아래: 턴 종료 버튼 하나
- 화면 위쪽 중앙: 턴 순서 초상화 줄만 아주 얇게
- ROUND와 목표는 화면 왼쪽 위에 아주 작게

아군 3명의 HP는 전장 위 캐릭터 머리 위 작은 바로만 표시한다.
적 정보도 적 머리 위 바로만.

전장이 최대로 넓게 보인다. 정보는 필요할 때 탭해서 연다는 전제.
```

## 9안 — 상단 정보 / 하단 조작 분리

```
[배치]
"읽는 것은 전부 위, 누르는 것은 전부 아래"로 엄격히 나눈다.

상단 띠 (읽기 전용): 화면 폭을 가로지르는 긴 나무 테두리 패널 하나.
  그 안에 왼쪽부터 ROUND 1 → 아군 3명 상태(초상화·HP·AP를 가로로 나란히)
  → 턴 순서 초상화 줄 → 선택된 적 정보 → 목표

하단 띠 (조작 전용): 명령 카드 6장이 한 줄로. 카드가 크고 터치하기 좋다.
  오른쪽 끝에 턴 종료 버튼. 하단이 상단보다 두껍다.

전장은 그 사이 중앙에 넓게.

정보와 조작이 섞이지 않아 학습이 쉽다. 다만 상단이 길어 눈이 이동한다.
```

## 10안 — 상황 전환형 (스킬 조준 중)

          독수리 초상화, HP 50/50, 방어 0, 예상 피해 8~14
