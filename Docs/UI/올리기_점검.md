## 0. 두 곳에 나눠 올린다

| | 무엇 | 어디 |
|---|---|---|
| **git** | 코드 · 굽는 도구 · WBP · ini · 문서 | `codex/safe-center-full-implementation` → PR |
| **SVN** | 그림(uasset) · 글꼴 | `^/RD/SVN` |

**경계는 `Content/SVN` 이다.** 그 아래는 SVN 작업본을 정션으로 걸어 둔 것이라
git 이 안 본다. 그 밖은 전부 git 이다.
