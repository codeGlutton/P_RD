# KayKit UI 키트 4차-재질우선판 — 재질이 아트톤을 이긴다 (프레임 4 + 버튼 2 + 면 6)

> 4차(단단함)·4차-보강(재질)을 **대체**한다. 이 문서 하나만 주면 된다.
>
> 지금까지의 우선순위는 "아트톤 유지 > 재질"이었고, 그 결과 재질이 계속
> 밋밋하게 나왔다. **이번에는 뒤집는다: 아트톤과 재질이 충돌하면 재질이
> 이긴다.** 아트톤은 팔레트와 실루엣으로만 지키고, 표면은 재질에 내준다.

## 우선순위 — 충돌하면 위가 이긴다

1. **조립 규격** — 치수·절단 좌표·타일 무결성·투명 영역. 이건 협상 불가
2. **재질** — 나무는 나무로, 강철은 강철로. 화면에서 만져질 듯 읽혀야 한다
3. **값 구조** — 어두운 윤곽, 밝은 면, 면-프레임 분리
4. **아트톤** — 팔레트 색 계열과 저폴리 실루엣. 표면 질감은 여기서 뺀다

## 무엇이 풀리는가 (지금까지 금지였던 것)

| 항목 | 이전 | 이번 |
| --- | --- | --- |
| 표면 결 | 금지 ("깨끗한 면") | **허용.** 나뭇결·브러시드 메탈 결·정 자국을 그린다 |
| 스펙큘러 | "반사 하이라이트 거의 없음" | **금속에는 진짜 광을 허용.** 좁고 강한 스펙큘러 밴드 |
| 요철 깊이 | 은은하게 | **깊게.** 홈은 그림자가 지고 돌출부는 빛을 받는다 |
| 모서리 마모 | 금지 | **에지웨어 허용.** 모서리가 닳아 밝아진 표현 |

## 무엇이 여전히 금지인가 (이 선을 넘으면 다른 게임이 된다)

- **사진 텍스처 소스 합성.** 그리는 것이지 붙이는 게 아니다
- **얼룩·때·러스트·그런지.** 마모는 *모서리에만*, 면 가운데는 깨끗하게
- **툰 외곽선.** 어두운 윤곽은 재질의 그림자이지 잉크 선이 아니다
- **잔무늬 과밀.** 결은 실제 표시 크기(띠 16~32px)에서 읽히는 밀도까지만.
  그보다 가늘면 노이즈로 뭉갠다
- 팔레트 이탈. 색 계열은 지정값 안에서만

## 공통 지시 (열두 장 모두 그대로 붙일 것)

```
ImageGen으로 그릴 것. 코드로 도형을 그려서 이미지를 만들지 말 것.

[방향]
스타일라이즈드 게임 UI 아트. 저폴리 판타지 보드게임의 실물 소품처럼,
재질이 만져질 듯 그린다. 사진 합성이 아니라 회화적 렌더다.

[우선순위]
재질 표현이 우선이다. "깨끗하고 무광"이라는 이전 지시는 폐기한다.
나무는 결이 보이고, 강철은 빛나고, 석재는 정으로 쪼아 낸 자국이 남는다.
단, 얼룩·때·러스트는 금지. 마모는 모서리에만.

[값 구조 — 유지]
- 바깥 가장자리: 거의 검정인 어두운 윤곽 (밝기 40~70)
- 빛 받는 면: 나무 190+, 금속 스펙큘러 피크 230+
- 안쪽 접합선: 어두운 홈 (밝기 50~80)
- 채도는 깊고 진하게. 회색 섞인 파스텔 금지

[조명]
빛은 왼쪽 위 45도. 재질마다 빛이 다르게 반응하는 것이 핵심이다:
나무는 부드럽게 퍼지고, 강철은 좁고 강하게 반짝이고, 석재는 요철의
그림자로 답한다.

[기술 제약]
- 정투영 정면. 조각 바깥 픽셀은 완전 투명 (면 텍스처만 불투명 512x512)
- 캔버스 크기는 지정값 그대로. 워터마크·설명 글자·격자 금지
- 한 이미지에 하나. 시트 금지
```

## A. 프레임 원판 4장

파일명·치수·절단 좌표는 이전과 완전히 동일. 덮어쓰기.

### A-1 두꺼운 나무 프레임 — 1024×768, 띠 128px

```
[그릴 것]
두꺼운 참나무 몰딩 테두리. 안은 비어 있다.

재질 -- 이번엔 진짜 나무처럼:
- 몰딩을 따라 길고 유려한 나뭇결이 흐른다. 결선은 손으로 그린 듯 매끈한
  곡선이고, 띠 두께 안에 3~5줄이 읽힌다
- 옹이 1~2개. 결이 옹이를 감싸며 휘어간다
- 널 이음선 1개. 이음선 양쪽의 결 방향과 색조가 살짝 다르다
- 깎인 모서리(chamfer)는 닳아서 한 단 밝다 (에지웨어)
- 결 홈에는 그림자가 지고, 결 사이 돌출부는 빛을 받는다 -- 요철이 깊다
- 하이라이트는 넓고 따뜻하게 윗면을 채운다. 왁스 먹인 목재의 은은한 광

값 구조: 바깥 윤곽 40~70 / 윗면 190+ / 옆면 #8B5E3C / 안쪽 접합선 50~80.
모서리에 금속 코너 브래킷 + 볼트 두 개. 브래킷은 강철 어휘(아래 A-3)를
따른다. 직선 구간에 볼트 없음. 네 변 같은 단면.

[치수] 1024x768, 투명 배경, 띠 정확히 128px, 브래킷 각 구석 256x256 안.
```

### A-2 얇은 나무 프레임 — 512×384, 띠 64px
A-1과 같은 재질, 결 2~3줄·옹이 없음으로 절제 (띠가 얇다).

### A-3 두꺼운 금속 프레임 — 1024×768, 띠 128px

```
[그릴 것]
단조 강철 몰딩 테두리.

재질 -- 이번엔 진짜 강철처럼:
- 표면에 브러시드 결: 몰딩 방향으로 아주 가는 결이 은은하게 흐른다
- 빛 받는 모서리에 좁고 강한 스펙큘러 밴드 (밝기 230+). 금속은 여기서
  결정된다 -- 넓게 퍼지면 플라스틱이다
- 판재 이음새 1~2개: 단차가 뚜렷해서 한쪽 모서리는 빛을 받고 반대쪽은
  그림자를 드리운다
- 베벨의 명암 경계는 칼같이 정확하다
- 모서리가 살짝 닳아 밝다 (에지웨어). 러스트·얼룩은 금지
- 볼트 머리는 돔형으로 돌출 -- 위쪽 하이라이트 점 + 아래쪽 눌린 그림자

값 구조: 바깥 윤곽 40~70 / 스펙큘러 230+ / 판재 면 #9AA0A9 /
안쪽 접합선 50~80. 차가운 청회색만. 코너 블록 + 볼트. 직선 구간 장식 없음.

[치수] A-1과 동일 규격.
```

### A-4 얇은 금속 프레임 — 512×384, 띠 64px
A-3과 같은 재질, 이음새 1개·브러시드 결 더 절제.

**절단**: 동일 좌표에서 `Corner_T/Corner_B/Link_T/Link_B/Link_S`.
파일명 `KK_HFrame_*` `KK_LFrame_*` `KK_MFrame_*` `KK_MLFrame_*`.

## B. 볼록 버튼 2장 — 1024×256, 모서리 128×128

```
옻칠한 주황 나무 버튼. A-1의 나무 어휘를 따르되:
- 결은 은은하게 1~2줄 (누르는 면은 비교적 깨끗하게)
- 옻칠의 광: 윗면 하이라이트가 나무보다 한 단 매끄럽고 또렷하다
- 밑단 그림자는 깊게 (#5A3220 이하) -- 버튼이 판에서 확실히 떠 보이게
- 모서리 에지웨어로 실루엣이 밝게 잡힌다
평시(_Up)/눌림(_Down) 실루엣 1px 일치. 눌림은 밑단이 사라지고
윗면 광이 그늘로 바뀐다.
```

## C. 면 6장 — 512×512 불투명, 네 변 무한 반복

```
재질 우선으로 다시:

석재(3종): 다각형 조각 모자이크. 조각 경계는 깊은 줄눈 -- 그림자가 진다.
  조각 표면에 정으로 쪼아 낸 자국 2~3개씩 (얕은 눌림, 그림자 동반).
  조각마다 색조가 미묘하게 다르다 (붉은 기 / 푸른 기).
  조각 모서리는 빛을 받아 얇게 밝다.

나무(2종): 세로 널빤지 4~6장. 널마다 결이 흐르고 (널당 2~3줄, 유려한 곡선),
  널 사이 이음선은 깊은 그림자 골. 널마다 색조 차. 옹이는 전체에 1~2개만.

양피지(1종): 섬유 결이 은은하게 보인다 (가늘고 불규칙한 가로 결).
  가장자리로 갈수록 눌리고 어두워진다. 얕은 들뜸 2~3곳에 부드러운 그림자.
  얼룩·태운 자국 금지.

공통: 조명 그라데이션 금지(코드가 얹는다). 네 변 무한 반복.
반복했을 때 알아볼 수 있는 특징(큰 옹이·특이한 조각)이 눈에 띄면 실패다 --
특징 요소는 작게, 고르게 흩어서.
```

## 검수

조립 규격(치수·이음 단면·타일 무결성)과 값 구조(윤곽≤70 · 대비폭≥120 ·
면-프레임 분리≥65)는 그대로. 재질 항목을 이번 기준으로 조정한다.

| 항목 | 판정 | 비고 |
| --- | --- | --- |
| **하이라이트 밴드 폭** | 금속 ≤ 20% / 나무 ≥ 35% | 재질 판별식, 유지 |
| **금속 스펙큘러 피크** | 최대 밝기 ≥ 230 | 이전 200에서 상향 |
| **나무 결 밀도** | 단면 프로파일 어두운 골 3~5개 | 이전 2~4에서 상향 |
| **면 국소 대비** | 3×3 P99가 **2.5~6.0** | 하한 신설 -- 정 자국·결이 실제로 있는지. 상한은 노이즈 방지 |
| **면 plateau** | 이웃 0.5 이내 픽셀 ≥ 40% | 요철이 늘어도 바탕은 평탄한 조각이어야 한다 (이전 60%에서 완화) |
| **면 색조 변조** | 조각/널별 R/B 비율 표준편차 > 0 | 유지 |
| **타일 반복 가시성** | 4×4 자기상관 봉우리 없음 | 옹이·특이 조각이 반복 무늬를 만들면 실패 |

**한 장이라도 벗어나면 그 원판만 다시. 그림에 코드를 맞추지 않는다.**
