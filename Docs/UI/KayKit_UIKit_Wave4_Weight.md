# KayKit UI 키트 4차 — "단단함" 재발주 (프레임 4 + 버튼 2 + 면 6)

인게임과 목업을 나란히 놓은 결론: **물빠진 가벼운 느낌**. 원인을 픽셀로 재서
확정했다. 형태의 문제가 아니라 **값(명암) 구조의 문제**다.

## 무엇이 빠졌는가 — 실측

목업의 프레임 단면은 4단계다:

```
[거의 검정인 외곽선] → [밝은 금속/나무 면] → [그늘 면] → [어두운 접합선] → 면
```

이 어두운 양끝이 프레임을 화면에 **고정(anchor)**한다. 지금 아트를 재면:

| 조각 | 최소 | 최대 | 대비폭 | 판정 |
| --- | --- | --- | --- | --- |
| 금속 프레임 이음 | **117** | 200 | 83 | 어두운 외곽선이 **없다**. 밝은 쪽에서만 논다 |
| 나무 프레임 이음 | 77 | **111** | **34** | 전체가 중간톤. 밝은 면도 어두운 선도 없다 |
| 버튼 이음 | 77 | 200 | 123 | 통과 — 화면에서 유일하게 단단해 보이는 이유 |

면과 프레임의 값 분리:

| 카드 | 면 평균 | 프레임 밝은 면 | 분리 |
| --- | --- | --- | --- |
| 스킬 카드 | 150 | 200 | +50 |
| **아군 카드** | 98 | 111 | **+13** |
| 턴 종료 | 115 | 164 | +49 |

아군 카드는 면과 프레임이 사실상 같은 값이라 "프레임이 면을 물고 있다"는
읽기가 성립하지 않는다. 그리고 스킬 카드 면(150)은 목업(~110)보다 한참
밝아서 흰 글자가 안 선다.

**결론: 12장 전부 재생성한다. 형태·치수·절단 좌표는 그대로, 값 구조만 바꾼다.**

## 공통 지시 (열두 장 모두 그대로 붙일 것)

```
ImageGen으로 그릴 것. 코드로 도형을 그려서 이미지를 만들지 말 것.

[스타일 — KayKit]
Kay Lousberg의 KayKit 에셋 팩과 같은 톤. 저폴리 3D 정면 렌더.
면이 크고 각져 있으며 모서리는 굵게 깎였다. 무광 플라스틱/점토.
외곽선(툰 라인) 없음. 노이즈·긁힘·그런지 금지. 손그림 붓질 금지.

[이번 발주의 핵심 — 값 구조]
지난 결과물은 형태는 맞았지만 명암이 전부 중간~밝은 값에 몰려서 물빠진
파스텔이 됐다. 이번에는 어두운 값을 반드시 쓴다.

- 모든 프레임과 버튼은 바깥 가장자리에 거의 검정에 가까운 어두운 윤곽
  (밝기 40~70)이 있어야 한다. 이 선이 UI를 화면에 고정한다.
- 빛을 받는 면은 확실히 밝게(밝기 190 이상), 그늘 면은 확실히 어둡게.
  중간톤 하나로 뭉개지 말 것.
- 채도를 겁내지 말 것. 나무는 진한 오렌지-브라운, 금속은 차가운 강철.
  회색이 섞인 흐린 파스텔 금지.

[조명]
빛은 왼쪽 위 45도. 위쪽 면이 밝고 아래쪽 면이 어둡다.

[기술 제약]
- 정투영 정면. 조각 바깥 픽셀은 완전 투명(면 텍스처만 불투명 512x512)
- 캔버스 크기는 지정값 그대로. 워터마크·설명 글자·격자 금지
- 한 이미지에 하나. 시트 금지
```

## A. 프레임 원판 4장 (재생성)

파일명·치수·절단 좌표는 3차와 완전히 동일하다. 값 구조만 바뀐다.

### A-1 두꺼운 나무 프레임 원판 — 1024×768, 띠 128px

```
[그릴 것]
완성된 UI 패널 테두리 한 장. 안은 비어 있다.

굵게 깎인 나무 몰딩이 사각형을 두른다. 단면의 값 구조가 핵심이다:
- 바깥 가장자리: 거의 검정에 가까운 진한 초콜릿 윤곽 (밝기 40~70)
- 빛 받는 윗면: 밝은 오렌지-브라운 (#C87A4A, 밝기 190 이상)
- 옆면: 중간 나무색 (#8B5E3C)
- 안쪽 가장자리: 다시 어두운 접합선 (밝기 50~80). 면과 만나는 자리다

모서리에는 금속 코너 브래킷 + 리벳 두 개씩. 브래킷도 같은 규칙 --
어두운 윤곽 안에 밝은 강철 면.
직선 구간에는 리벳도 장식도 없다. 단면이 일정한 몰딩.
네 변의 몰딩은 완전히 같은 단면. 빛 방향만 다르다.

[치수]
캔버스 1024x768, 투명 배경. 테두리 띠 두께 정확히 128px.
모서리 브래킷은 각 구석 256x256 안. 가운데는 완전 투명.
```

### A-2 얇은 나무 프레임 원판 — 512×384, 띠 64px
A-1과 같은 값 구조, 장식만 단순하게 (코너 리벳 하나씩).

### A-3 두꺼운 금속 프레임 원판 — 1024×768, 띠 128px

```
A-1과 같은 사각 테두리, 재질만 강철.
- 바깥 윤곽: 거의 검정인 어두운 강철 (밝기 40~70)
- 빛 받는 윗면: 밝은 은색 (#D8DCE2, 밝기 200 이상)
- 옆면: 중간 강철 (#9AA0A9)
- 안쪽 접합선: 어두운 홈 (밝기 50~80)
차가운 회색. 따뜻한 기 섞지 말 것. 코너 블록 + 리벳 두 개씩.
직선 구간 장식 없음.
```

### A-4 얇은 금속 프레임 원판 — 512×384, 띠 64px

**절단**: 3차와 동일 좌표에서 `Corner_T/Corner_B/Link_T/Link_B/Link_S`.
파일명 `KK_HFrame_*` `KK_LFrame_*` `KK_MFrame_*` `KK_MLFrame_*` (덮어쓰기).

## B. 볼록 버튼 원판 2장 (재생성 — 값만 더)

버튼은 대비폭 123으로 유일하게 통과였지만, 프레임이 전부 진해지면 상대적으로
다시 밝아 보인다. 같은 규칙으로 한 단계 더:

```
3차 버튼과 같은 형태·같은 크기 (1024x256, 모서리 128x128).
- 바깥 윤곽을 어두운 초콜릿 (밝기 40~70)으로 한 겹 두를 것
- 윗면 하이라이트는 유지, 밑단은 더 진하게 (#5A3220 근방)
평시(_Up)와 눌림(_Down)의 실루엣은 1px도 다르면 안 된다.
```

## C. 면 6장 (재생성 — 어둡게, 다각형 결 유지)

3차 면의 다각형 결은 정답이었다. **밝기만 틀렸다.** 스킬 카드 면이 150인데
목업은 ~110이다. 흰 글자가 서려면 면이 어두워야 한다.

```
3차 면과 같은 다각형 모자이크 (조각 크기 캔버스의 1/8~1/4, 경계 각지고
선명, 이웃 조각 밝기 차이는 은은하게). 기준색만 아래로 내린다.

조명 그라데이션 금지(코드가 얹는다). 노이즈·긁힘 금지.
캔버스 512x512 불투명. 네 변 무한 반복.
```

| 파일 | 기준색 (어두워진 값) | 평균 밝기 목표 |
| --- | --- | --- |
| `KK_Fill_Stone` | `#787E88` | 110~125 |
| `KK_Fill_Stone_Skill` | `#66788F` | 100~115 |
| `KK_Fill_Stone_Enemy` | `#8F5A58` | 90~105 |
| `KK_Fill_Wood` | `#6E4A2E` | 75~90 |
| `KK_Fill_Wood_Active` | `#96612F` | 100~115 |
| `KK_Fill_Parchment` | `#EAD9B8` | 200~215 (양피지만 밝게 유지) |

## 검수 — 이번 항목

기존 검수(치수·이음·팔레트·다각형 결)에 **값 구조** 항목을 더한다.

| 항목 | 판정 | 왜 |
| --- | --- | --- |
| **프레임 어두운 윤곽** | 단면 프로파일 최소값 ≤ 70 | 3차 금속이 117이었다. 어두운 앵커가 없으면 뜬다 |
| **프레임 밝은 면** | 단면 프로파일 최대값 ≥ 190 | 나무가 111이었다 |
| **대비폭** | 최대-최소 ≥ 120 | 나무가 34였다 |
| **명암 전환 수** | 프로파일 방향 전환 ≥ 4회 | 외곽어둠-밝음-그늘-접합어둠 구조 확인 |
| **면-프레임 분리** | 프레임 밝은 면(P90) − 면 평균 ≥ 65 | 아군 카드가 +13이었다 |
| **면 평균 밝기** | 위 표의 범위 | 스킬 면 150은 흰 글자를 죽인다 |

**한 장이라도 벗어나면 그 원판만 다시. 그림에 코드를 맞추지 않는다.**

## 코드 쪽에서 같이 바뀌는 것 (내 몫)

물빠짐의 일부는 아트가 아니라 **내 틴트다.** 시안 밝기를 흉내내려고
`SURFACES`의 곱색을 올려놨는데, 어두워진 새 면이 오면 전부 `WHITE`로
되돌린다 — 역할 색은 텍스처가 갖고, 코드는 곱하지 않는다.
림 라이트(0.22)와 접합선(0.30)의 알파도 각각 0.35 / 0.50으로 올린다.
2px짜리 선이 그 알파로는 안 보였다.
