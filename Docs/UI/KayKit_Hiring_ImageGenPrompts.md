# 용병 고용 화면 10안 — Codex ImageGen 프롬프트

> 기존 캐릭터 선택(3명 중 1명)을 폐기하고 **용병 고용(6명 중 3명)**으로 바꾼다.
> 컨셉은 확정: **중세 판타지 게시판에 용병 이력서가 붙어 있다.** 열 개 안은
> 그 컨셉 안에서 배치와 조작 흐름만 달리한다.
>
> 사용법: 아래 **공통 지시**를 각 안 앞에 붙여 한 장씩 생성한다.
> 열 장이 같은 용병·같은 수치·같은 선택 상태여야 배치만 비교된다.

---

## 공통 지시 (열 개 프롬프트 앞에 그대로 붙일 것)

```
ImageGen으로 그릴 것. 코드로 도형을 그려서 이미지를 만들지 말 것.

[캔버스]
1920 x 1080, 가로 모바일 게임 화면. UI 목업 한 장.

[게임]
그리드 기반 턴제 전술 RPG. 로그라이크. 한국어 UI.
전투 전에 용병 6명 중 3명을 고용해 파티를 짠다. 이 화면이 그 고용 화면이다.

[미술 스타일 — KayKit]
Kay Lousberg의 KayKit 에셋 팩과 같은 톤. 저폴리 3D 정면 렌더 느낌.
- 면이 크고 각져 있으며 모서리는 굵게 깎였다. 무광 플라스틱/점토
- 패널·소품에는 거의 검정에 가까운 어두운 윤곽이 있어 단단히 고정돼 보인다
- 재질이 만져질 듯: 나무는 널빤지와 결, 금속은 좁고 선명한 하이라이트,
  양피지는 가장자리가 눌리고 살짝 어둡다
- 밝고 친근한 색, 채도 깊게. 회색 섞인 파스텔 금지
- 외곽선(툰 라인) 없음. 얼룩·때·러스트 금지 (마모는 모서리에만)
- 한글은 둥근 고딕(산스). 명조 금지. 이력서 제목만 손글씨 느낌 허용

[팔레트 — 이 색만 쓸 것]
석재/금속 밝은 회색 #C3C7CE · 중간 #9AA0A9 · 그늘 #6E747E
가죽 밝은 갈색 #A9653F · 어두운 갈색 #7A4529 · 나무 #8B5E3C
빨강 #D2453F · 초록 #3E8E5A · 보라 #6B5CA5
금색 #E8B84B · 크림(양피지) #F2E3C6 · 파랑 #4A82C8

[무대 — 모든 안이 공유하는 배경]
길드 앞 나무 게시판. 게시판은 굵은 나무 프레임 + 코르크/판자 면이고,
이력서는 양피지 한 장씩이다. 이력서는 압정이나 못으로 붙어 있고,
살짝 비뚤어져도 된다. 배경은 길드 건물 외벽이나 실내(어둡게, 게시판이
주인공이 되게).

[이력서 한 장에 반드시 들어가는 것]
초상화(원형 또는 사각), 이름/직업, HP, 스킬 2개 이름, 고용비(금화 아이콘+숫자)

[여섯 용병 — 열 장 모두 같은 수치]
1 기사    HP 100  방패 강타 · 반격 태세   40골드   ← 선택됨
2 궁수    HP 80   관통 사격 · 조준        35골드   ← 선택됨
3 마법사  HP 70   화염구 · 빙결           45골드   ← 지금 검토 중 (강조)
4 도적    HP 75   기습 · 은신             30골드
5 성직자  HP 85   치유 · 축복             40골드
6 야만전사 HP 120  대검 휘두르기 · 분노    50골드

[선택 상태 — 열 장 모두 동일]
- 기사·궁수는 이미 선택됨: 이력서에 붉은 밀랍 도장 "고용"이 찍혀 있다
- 마법사는 지금 검토 중: 금색 강조 (안마다 방식은 다름)
- 화면 어딘가에 파티 슬롯 3칸: 기사·궁수 초상이 차 있고 셋째 칸은 비어 있다
- 소지금 120골드 표시
- "출발" 버튼: 아직 3명이 안 찼으므로 비활성(어둡게)
- 화면 제목: 게시판 위 나무 현판에 "용병 모집"

[하지 말 것]
- 주사위 요소 금지. 영어 UI 텍스트 금지
- 사진 합성 금지. 워터마크·설명 캡션·격자 가이드 금지
- 반투명 유리·블러·네온 금지

[모바일 제약]
- 터치 대상은 화면 높이의 5% 이상. 이력서 한 장이 곧 버튼이다
- 하단 모서리가 엄지 자리. 출발 버튼은 오른쪽 아래가 기본
```

## 1안 — 정직한 격자 게시판

```
[배치]
큰 게시판 하나가 화면 중앙을 채우고, 이력서 6장이 2행 3열로 붙어 있다.
장마다 살짝 비뚤어진 각도가 다르다 (붙인 사람이 사람이라서).

기사·궁수 이력서에 붉은 밀랍 도장. 마법사 이력서는 금색 테두리로 강조되고
다른 장보다 살짝 크다.
게시판 위: "용병 모집" 현판. 왼쪽 위 구석에 소지금 120골드 주머니.
하단 띠: 왼쪽에 파티 슬롯 3칸(기사·궁수 초상 + 빈 칸), 오른쪽에 출발
버튼(비활성).

가장 보편적인 구성. 여섯 장이 동시에 다 보인다.
```

## 2안 — 게시판 + 상세 패널

```
[배치]
왼쪽 55%: 게시판. 이력서 6장이 2행 3열로, 각 장은 요약만 (초상·이름·고용비).
오른쪽 45%: 검토 중인 마법사의 큰 이력서 한 장. 초상화 크게, HP, 스킬 2개
           (아이콘+이름+한 줄 설명), 고용비, 그리고 "고용하기" 버튼.

게시판 쪽 마법사 요약 장에 금색 테두리 -- 지금 오른쪽에 펼쳐진 게 이거라는
연결이 읽힌다. 기사·궁수 요약 장에는 밀랍 도장.
하단: 파티 슬롯 3칸 + 소지금 + 출발 버튼(비활성).

요약과 상세를 나눠 이력서 한 장의 정보량을 줄인다.
```

## 3안 — 책상 트레이

```
[배치]
화면 위 2/3: 게시판에 이력서 6장 (2행 3열, 요약형).
화면 아래 1/3: 카메라 앞 나무 책상. 책상 위에 선택된 용병의 이력서가
              실물로 놓인다 -- 기사·궁수 장이 이미 놓여 있고, 세 번째
              자리는 빈 양피지 자리 표시만.

게시판에서 뽑은 장이 책상으로 내려온다는 은유. 뽑힌 자리는 게시판에
압정과 밝은 자국만 남는다 (기사·궁수 자리가 비어 있고 자국이 보인다).
책상 오른쪽 끝: 소지금 주머니와 출발 버튼.

"고른다 = 떼서 가져온다"가 물리적으로 보인다.
```

## 4안 — 두루마리 세로 6개

```
[배치]
게시판 대신 가로대에 두루마리 6개가 세로로 걸려 있다. 두루마리마다
용병 하나 -- 위에 초상, 아래로 이름·HP·스킬·고용비가 세로로 흐른다.

기사·궁수 두루마리는 붉은 끈으로 묶인 밀랍 도장. 마법사 두루마리는
금색으로 강조되고 살짝 더 길게 펼쳐져 스킬 설명 한 줄이 더 보인다.
상단: 현판과 소지금. 하단: 파티 슬롯 3칸 + 출발 버튼.

세로 리듬이라 6명이 나란히 비교된다. 한 장의 정보량은 적다.
```

## 5안 — 수배서 벽

```
[배치]
게시판이 아니라 길드 외벽 전체가 캔버스다. 크고 작은 수배서(WANTED 포스터
양식이지만 문구는 한글 "용병")가 벽에 6장, 자유롭게 겹치듯 붙어 있다.
큰 장 둘(기사·야만전사), 중간 셋, 작은 하나 -- 크기가 계급이 아니라
붙인 순서라는 느낌으로 무작위.

각 수배서: 초상이 크고 이름·고용비가 굵게. HP·스킬은 작게.
기사·궁수에 밀랍 도장, 마법사에 금색 강조.
하단 왼쪽: 파티 슬롯 3칸. 하단 오른쪽: 소지금 + 출발.

가장 그림 같은 안. 정보 정렬은 가장 느슨하다.
```

## 6안 — 길드 장부

```
[배치]
카메라가 펼쳐진 큰 장부(책)를 내려다본다. 왼쪽 페이지: 용병 6명이
줄글 목록 (한 줄에 작은 초상·이름·HP·고용비, 선택된 줄에 도장 마크).
오른쪽 페이지: 검토 중인 마법사 상세 -- 초상 크게, 스킬 2개 설명,
고용 버튼.

책 밖 아래: 파티 슬롯 3칸과 출발 버튼이 책상 위 부속품으로.
소지금은 책상 구석 금화 더미 + 숫자.

게시판 컨셉의 실내 변형. 목록형이라 비교가 빠르다.
```

## 7안 — 라인업 (실물 + 명패)

```
[배치]
게시판 앞에 용병 6명이 실물(KayKit 치비 캐릭터)로 나란히 서 있다.
각 캐릭터 발밑에 나무 명패: 이름·고용비만.
머리 위에는 HP와 스킬 2개가 적힌 작은 팻말.

기사·궁수 위에는 붉은 "고용" 리본. 마법사는 금색 원 안에 서 있고
스포트라이트처럼 살짝 밝다.
배경 게시판에는 빈 이력서 자국들 (이미 떼어 왔다는 암시).
하단: 파티 슬롯 3칸 + 소지금 + 출발.

캐릭터 실물이 보여서 고르는 재미가 크다. 수치 비교는 약하다.
```

## 8안 — 면접 테이블

```
[배치]
탁자 맞은편에 마법사 한 명이 크게 앉아 있다 (상반신, 화면 오른쪽 40%).
왼쪽에는 마법사의 이력서가 크게: 초상 없이(실물이 있으니) 이름·HP·
스킬 2개 상세 설명·고용비, 그리고 "고용" / "다음" 버튼 2개.

하단 띠: 나머지 5명의 작은 초상 썸네일 줄 -- 기사·궁수에 도장 마크,
탭하면 그 용병이 맞은편에 앉는다는 암시.
상단: 현판·소지금. 출발 버튼은 오른쪽 아래.

한 명씩 깊게 보는 흐름. 여섯 명 훑기는 느리다.
```

## 9안 — 나란히 비교

```
[배치]
검토 중인 두 장을 나란히 크게 놓고 비교한다. 화면 중앙에 마법사와
성직자의 이력서가 좌우로 큼직하게 -- 같은 항목이 같은 높이에 정렬돼
(HP는 HP끼리, 고용비는 고용비끼리) 줄만 맞춰 읽으면 비교가 끝난다.
마법사 쪽이 금색 강조.

상단: 6명 전체의 작은 초상 줄 (기사·궁수에 도장, 마법사·성직자가
지금 아래에 펼쳐져 있다는 밝은 표시).
하단: 파티 슬롯 3칸 + 소지금 + 출발.

스탯 비교가 가장 정확하다. 두 명씩만 볼 수 있다.
```

## 10안 — 출정 준비 (마차)

```
[배치]
왼쪽 60%: 게시판에 이력서 6장 (2행 3열 요약형, 도장·강조 규칙 동일).
오른쪽 40%: 출정 마차가 서 있고, 고용된 용병이 실물로 마차에 타 있다 --
           기사와 궁수가 이미 앉아 있고, 빈자리 하나가 점선 실루엣으로
           비어 있다.

이력서를 고르면 캐릭터가 마차에 올라탄다는 은유. 파티 슬롯이 UI 칸이
아니라 마차 좌석이다.
마차 아래: 소지금과 출발 버튼 (마차 바퀴 옆 나무 팻말로).

선택 결과가 장면으로 보인다. 오른쪽이 넓어 이력서가 작아진다.
```

## 받고 나서 볼 것

| 항목 | 왜 |
| --- | --- |
| 여섯 명이 한눈에 비교되는가 | 6 중 3 선택의 핵심 과업 |
| 선택됨 / 검토 중 / 대기가 3단계로 갈리는가 | 도장·금색·무표시가 실제로 구분되는지 |
| 남은 한 자리가 보이는가 | "몇 명 더 골라야 하나"가 즉답되어야 한다 |
| 고용비와 소지금이 연결되는가 | 예산 안에서 고르는 긴장이 이 화면의 재미다 |
| 이력서 한 장이 엄지로 눌리는 크기인가 | 이력서가 곧 버튼이다 |
| 전투 HUD와 같은 세계로 보이는가 | 프레임·양피지·도장이 KayKit 키트 톤인지 |

## 이 화면이 확정되면 필요한 새 부품 (미리 알림)

게시판 판면, 압정/못, 밀랍 도장, 양피지 이력서 원판(빈 양식), 나무 현판,
금화 주머니, 마차(10안 채택 시). **시안이 정해진 뒤에 발주한다** — 지금
뜨면 열 안이 같은 부품 제약에 묶인다.
