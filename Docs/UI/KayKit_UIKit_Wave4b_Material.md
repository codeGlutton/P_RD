# KayKit UI 키트 4차-보강 — 재질 강화판 (프레임 4 + 버튼 2 + 면 6)

> 4차(단단함) 문서를 **대체**한다. 이 문서 하나만 주면 된다.
> 값 구조(어두운 윤곽·밝은 면) 요구는 그대로 유지하고, 그 위에 **재질**을 얹는다.

## 왜 보강하는가

4차 중간 결과: 단단함(값 구조)은 잡히고 있다. 그런데 **나무가 나무로,
강철이 강철로 안 읽힌다.** 어두운 윤곽 + 밝은 면만으로는 "단단한 무언가"까지만
가고, 그게 무슨 재질인지는 말하지 못한다.

핵심 원칙: **KayKit에서 재질은 텍스처가 아니라 구조와 빛으로 말한다.**
- 사진 질감·노이즈·그런지를 넣으면 아트톤이 깨진다. 금지는 유지한다.
- 대신 재질마다 **깎인 방식**과 **빛이 꺾이는 방식**이 다르다. 그걸 그린다.

## 재질 어휘 — 이 문서의 심장

각 재질을 아래 어휘로만 표현한다. 디테일은 **적고 크게**. 게임에서 프레임
띠는 16~32px로 보이므로 잔무늬는 뭉개져 노이즈가 된다.

### 나무 (wood)
- **널빤지 분할**: 긴 변을 따라 1~2개의 널 이음선. 이음선은 어두운 골이다
- **깎은 결 홈**: 널 방향으로 길게 깎인 얕은 홈 2~3줄. 조각도로 판 자국이지
  나뭇결 사진이 아니다
- **널마다 색이 미묘하게 다르다**: 같은 갈색 안에서 한 널은 조금 붉고
  옆 널은 조금 노랗다
- **빛이 부드럽게 넘어간다**: 하이라이트가 넓고 경계가 완만하다. 무광 목재
- 모서리는 둥글게 깎였고(chamfer), 깎인 면이 한 단 밝다

### 강철 (metal)
- **판재 이음새**: 금속판 여러 장을 이어 붙인 직선 이음선. 이음선을 따라
  한쪽은 밝은 선, 한쪽은 어두운 선 (단차)
- **기계 베벨**: 모서리가 정확한 각도로 깎였고, 깎인 면의 명암 경계가 칼같다
- **좁고 선명한 하이라이트**: 빛 받는 모서리에 가늘고 또렷한 밝은 띠.
  나무의 넓은 하이라이트와 정반대 -- 이게 금속을 금속으로 읽게 한다
- **리벳/볼트**: 코너 브래킷에만. 볼트 머리에는 작은 하이라이트 점 하나
- 색은 차가운 청회색 계열에서만 논다. 따뜻한 기 금지

### 석재 (stone, 면 텍스처)
- **다각형 조각 모자이크** (3차에서 확립, 유지)
- **조각 경계에 얕은 홈**: 경계선이 이웃 조각보다 눈에 띄게 어둡다.
  줄눈(mortar)처럼 조각들이 물리적으로 맞물려 보이게 한다
- **조각마다 미묘한 색조 차**: 같은 회색 안에서 조금 푸르거나 조금 붉게
- 조각 표면 자체는 평탄하다. 조각 안에 잔무늬 금지

### 양피지 (parchment)
- **가장자리로 갈수록 미세하게 어두워진다** (오래 눌린 종이의 가장자리)
- 표면에 아주 얕고 넓은 굴곡 2~3곳 (구겨짐이 아니라 자연스러운 들뜸)
- 섬유 결·얼룩·태운 자국 금지

### 버튼 (주황 나무)
- 나무 어휘를 따르되 결 홈은 1줄로 절제 (누르는 물건은 면이 깨끗해야 한다)
- 윗면 하이라이트는 넓고 부드럽게, 밑단은 확실히 어둡게

## 공통 지시 (열두 장 모두 그대로 붙일 것)

```
ImageGen으로 그릴 것. 코드로 도형을 그려서 이미지를 만들지 말 것.

[스타일 — KayKit]
Kay Lousberg의 KayKit 에셋 팩과 같은 톤. 저폴리 3D 정면 렌더.
면이 크고 각져 있으며 모서리는 굵게 깎였다. 무광 플라스틱/점토.
외곽선(툰 라인) 없음. 사진 질감·노이즈·긁힘·그런지 금지. 손그림 붓질 금지.

[값 구조 — 지난 발주에서 확립, 유지]
- 바깥 가장자리에 거의 검정에 가까운 어두운 윤곽 (밝기 40~70)
- 빛 받는 면은 확실히 밝게 (나무 190 이상, 금속 200 이상)
- 안쪽 접합선은 다시 어둡게 (밝기 50~80)
- 채도를 겁내지 말 것. 회색 섞인 파스텔 금지

[재질 — 이번 보강의 핵심]
재질은 텍스처가 아니라 구조와 빛으로 말한다.
- 나무: 널 이음선 1~2개 + 길게 깎인 결 홈 2~3줄 + 널마다 미묘한 색 차.
  하이라이트는 넓고 부드럽다.
- 강철: 판재 이음새(단차 선) + 칼같은 베벨 + 가늘고 또렷한 모서리
  하이라이트. 하이라이트가 좁을수록 금속이다.
- 디테일은 적고 크게. 실제 표시 크기(띠 16~32px)에서 읽혀야 하며,
  잔무늬는 그 크기에서 노이즈가 된다.

[조명]
빛은 왼쪽 위 45도. 위쪽 면이 밝고 아래쪽 면이 어둡다.

[기술 제약]
- 정투영 정면. 조각 바깥 픽셀은 완전 투명 (면 텍스처만 불투명 512x512)
- 캔버스 크기는 지정값 그대로. 워터마크·설명 글자·격자 금지
- 한 이미지에 하나. 시트 금지
```

## A. 프레임 원판 4장

파일명·치수·절단 좌표는 3차와 완전히 동일. 덮어쓰기.

### A-1 두꺼운 나무 프레임 — 1024×768, 띠 128px

```
[그릴 것]
완성된 UI 패널 테두리. 안은 비어 있다.

굵게 깎인 나무 몰딩. 재질 표현:
- 몰딩 긴 방향으로 널 이음선 1개가 지나간다 (얕고 어두운 골)
- 널 방향으로 깎은 결 홈 2줄. 조각도로 판 자국처럼 길고 매끈하다
- 이음선을 경계로 두 널의 색이 미묘하게 다르다 (한쪽이 조금 붉다)
- 하이라이트는 넓고 부드럽게 윗면을 채운다

값 구조:
- 바깥 윤곽: 진한 초콜릿 (밝기 40~70)
- 윗면: 밝은 오렌지-브라운 #C87A4A 이상 (밝기 190+)
- 옆면: 중간 나무색 #8B5E3C
- 안쪽 접합선: 어두운 골 (밝기 50~80)

모서리에 금속 코너 브래킷 + 볼트 두 개 (볼트 머리에 하이라이트 점).
직선 구간에 볼트·장식 없음. 네 변 같은 단면, 빛 방향만 다름.

[치수] 캔버스 1024x768, 투명 배경, 띠 정확히 128px,
브래킷은 각 구석 256x256 안, 가운데 완전 투명.
```

### A-2 얇은 나무 프레임 — 512×384, 띠 64px
A-1과 같은 어휘, 결 홈은 1줄로 절제 (띠가 얇아 2줄은 뭉갠다).

### A-3 두꺼운 금속 프레임 — 1024×768, 띠 128px

```
[그릴 것]
강철 몰딩 테두리. 재질 표현:
- 몰딩이 여러 장의 판재를 이어 붙인 구조다. 긴 변마다 판재 이음새 1~2개
  (이음새는 한쪽 밝은 선 + 한쪽 어두운 선의 단차)
- 베벨의 명암 경계가 칼같이 정확하다
- 빛 받는 모서리를 따라 가늘고 또렷한 하이라이트 선이 달린다.
  넓게 퍼지는 하이라이트 금지 -- 좁을수록 금속이다

값 구조:
- 바깥 윤곽: 거의 검정인 어두운 강철 (밝기 40~70)
- 하이라이트 선: 밝은 은색 #D8DCE2 이상 (밝기 200+)
- 판재 면: 중간 강철 #9AA0A9
- 안쪽 접합선: 어두운 홈 (밝기 50~80)

차가운 청회색만. 코너 블록 + 볼트 두 개. 직선 구간 장식 없음.

[치수] A-1과 동일 규격.
```

### A-4 얇은 금속 프레임 — 512×384, 띠 64px
A-3과 같은 어휘, 판재 이음새 1개로 절제.

**절단**: 3차와 동일 좌표에서 `Corner_T/Corner_B/Link_T/Link_B/Link_S`.
파일명 `KK_HFrame_*` `KK_LFrame_*` `KK_MFrame_*` `KK_MLFrame_*`.

## B. 볼록 버튼 2장 — 1024×256, 모서리 128×128

```
주황 나무 버튼. 나무 어휘를 따르되 결 홈 1줄만 (누르는 면은 깨끗하게).
- 바깥 어두운 윤곽 (밝기 40~70)
- 윗면 하이라이트는 넓고 부드럽게, 밑단은 #5A3220 근방으로 확실히 어둡게
- 평시(_Up)와 눌림(_Down)의 실루엣은 1px도 다르면 안 된다.
  눌림은 밑단이 사라지고 판이 내려앉으며 윗면 하이라이트가 그늘로 바뀐다
```

## C. 면 6장 — 512×512 불투명, 네 변 무한 반복

```
다각형 조각 모자이크 (조각 크기 캔버스의 1/8~1/4, 경계 각지고 선명).

재질 보강 두 가지:
- 조각 경계에 얕은 홈: 경계선이 이웃 조각보다 눈에 띄게 어둡다.
  조각들이 물리적으로 맞물린 줄눈으로 읽혀야 한다
- 조각마다 미묘한 색조 차: 같은 기준색 안에서 조금 붉거나 조금 푸르게.
  밝기만 다르고 색이 같으면 플라스틱 판이 된다

나무 면(Wood 2종)은 다각형 대신 널빤지 분할을 쓴다: 세로로 긴 널 4~6장,
널마다 색조 차, 널 사이 어두운 이음선, 널 안에 결 홈 1~2줄.

조각/널 표면 자체는 평탄. 잔무늬·노이즈 금지.
조명 그라데이션 금지 (코드가 얹는다).
```

## 검수 — 재질 항목 추가

4차 값 구조 검수(윤곽≤70 · 밝은면≥190 · 대비폭≥120 · 전환≥4회 ·
면-프레임 분리≥65)는 그대로. 재질 판별을 더한다.

| 항목 | 판정 | 왜 |
| --- | --- | --- |
| **하이라이트 밴드 폭** | 금속: 띠 두께의 **20% 이하** / 나무: **35% 이상** | 좁은 하이라이트=금속, 넓은 하이라이트=나무. 이게 두 재질의 결정적 차이다 |
| **나무 결 홈** | 프레임 단면 프로파일에 국소 어두운 골 2~4개 | 결 홈·널 이음이 실제로 있는지 |
| **금속 판재 이음새** | 타일 축 방향 프로파일에 단차 1~2개 | 이음새가 실제로 있는지 |
| **면 줄눈** | 조각 경계 픽셀이 이웃 조각 평균보다 8 이상 어두움 | 경계가 홈으로 읽히는지 |
| **면 색조 변조** | 조각별 R/B 비율 표준편차가 0이 아님 (밝기만 다른 단색 금지) | 플라스틱 판 방지 |
| 타일 이음매 | 마주 보는 끝 픽셀줄 차이 ≤ 2 | 반복 무결성 (기존) |

**한 장이라도 벗어나면 그 원판만 다시. 그림에 코드를 맞추지 않는다.**
