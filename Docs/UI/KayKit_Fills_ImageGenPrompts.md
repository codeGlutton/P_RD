# KayKit 면(패널 바닥) 6장 재생성 — Codex ImageGen 프롬프트

> 이 문서만 있으면 된다. 다른 문서를 볼 필요 없다.
> 아래 **공통 지시**를 각 면 프롬프트 앞에 붙여 여섯 번 생성한다.

---

## 왜 다시 뽑는가

1차에 긁힌 얼룩(그런지)이 나와서 재발주하며 "거의 단색으로 보여야 한다,
밝기 차이 5% 이내"라고 못 박았다. 그게 과교정돼서 **면 재질이 통째로
사라졌다.** 실측:

| 파일 | 값 범위 | 표준편차 |
| --- | --- | --- |
| `KK_Fill_Stone` | 138~140 | 0.12 |
| `KK_Fill_Wood` | 103~106 | 0.58 |
| `KK_Fill_Parchment` | 212~215 | 0.54 |
| `KK_Fill_Stone_Skill` | 128~130 | 0.30 |
| `KK_Fill_Stone_Enemy` | **112~112** | 0.18 |
| `KK_Fill_Wood_Active` | 110~112 | 0.16 |

`KK_Fill_Stone_Enemy`는 최소값과 최대값이 같다. 완전한 단색이다. 512x512
텍스처를 쓰면서 값이 두 단계밖에 안 움직여서, 화면에 남는 건 코드가 얹는
세로 그라데이션 한 장뿐이다.

**"긁힌 얼룩"과 "완전한 단색" 사이가 정답이다.** 지난 두 번은 매번 한쪽
끝만 막아서 반대쪽 끝으로 갔다. 이번에는 위아래를 다 막는다.

---

## 공통 지시 (여섯 번 모두 그대로 붙일 것)

```
ImageGen으로 그릴 것. 코드로 도형을 그려서 이미지를 만들지 말 것.

[스타일 — KayKit]
Kay Lousberg의 KayKit 에셋 팩(Adventurers, Skeletons, Dungeon)과 같은 톤.
- 저폴리 3D를 정면에서 렌더한 느낌. 면이 크고 각져 있다
- 재질은 무광 플라스틱/점토. 반사 하이라이트가 거의 없다
- 외곽선(툰 라인) 없음. 텍스처 노이즈·긁힘·오염 없음
- 손그림 붓질 느낌 금지. 사실적 질감 금지. 그런지·러스트 금지

[조명]
빛은 왼쪽 위 45도에서 온다. 다만 이건 패널 바닥이라 조명 그라데이션을
그려 넣지 말 것 -- 위아래 명암은 코드가 따로 얹는다. 면 자체는 고르게
밝아야 한다.

[기술 제약]
- 캔버스 512x512, 불투명 PNG. 알파 채널 없음
- 정투영 정면. 원근 기울기 금지
- 워터마크, 설명 글자, 격자 가이드, 치수 표시 금지
- 한 이미지에 면 하나. 시트 금지
```

## 면 프롬프트 (여섯 장 공통 본문)

색만 바꿔서 여섯 번 생성한다. 본문은 동일하다.

```
[그릴 것]
UI 패널 바닥에 깔 <재질> 면.

저폴리 3D를 정면에서 본 면이다. 큼직한 다각형 조각들이 서로 아주 조금씩
다른 밝기로 이어 붙어 있다. 조각 하나의 크기는 캔버스의 1/8 ~ 1/4 정도로
크고, 조각 경계는 각지고 선명하다. 삼각형과 사각형이 섞인 불규칙한 분할.

이웃한 조각끼리 밝기 차이는 눈에 겨우 보일 정도다. 멀리서 보면 한 색으로
읽히지만, 가까이 보면 면이 여러 조각으로 나뉜 게 보인다.

[하지 말 것 — 지난 두 번 다 여기서 틀렸다]
- 긁힌 자국, 얼룩, 반점, 붓질, 나뭇결 같은 잔무늬 (1차에서 이게 나왔다)
- 완전한 단색. 값이 두세 단계밖에 안 움직이는 평면 (2차에서 이게 나왔다)
- 노이즈, 그레인, 디더링 같은 픽셀 단위 잡티
- 부드러운 그라데이션 한 장. 조각 경계가 반드시 있어야 한다
- 조명 그라데이션(위가 밝고 아래가 어두운 것). 코드가 따로 얹는다

[치수]
캔버스 512x512, 불투명.
상하좌우로 무한 반복시키므로 네 변이 반대편 변과 정확히 이어져야 한다.
4x4로 이어 붙였을 때 "저 무늬가 또 나왔네"라고 알아볼 수 있는 특징이
하나도 없어야 한다. 눈에 띄는 큰 도형, 밝은 점, 어두운 얼룩 금지.

[검수 통과 기준 — 숫자로 건다]
- 8x8 블록 평균끼리의 표준편차: 3.0 이상 8.0 이하
- 3x3 국소 대비 상위 1%: 2.5 이하
- 전체 값 범위(최대 - 최소): 12 이상 40 이하
```

## 여섯 장의 색

`<재질>` 자리와 색만 아래 표대로 바꾼다.

| # | 파일 | `<재질>` | 기준색 | 쓰임 |
| --- | --- | --- | --- | --- |
| 1 | `KK_Fill_Stone` | 석재 | `#9AA0A9` | 범용 |
| 2 | `KK_Fill_Stone_Skill` | 푸른 기 도는 석재 | `#8794A6` | 스킬 카드 |
| 3 | `KK_Fill_Stone_Enemy` | 붉은 기 도는 석재 | `#A6797A` | 적 정보 |
| 4 | `KK_Fill_Wood` | 나무 | `#8B5E3C` | 아군 카드 |
| 5 | `KK_Fill_Wood_Active` | 밝은 나무 | `#A9713F` | 차례인 유닛 · 버튼 |
| 6 | `KK_Fill_Parchment` | 양피지 | `#F2E3C6` | 라운드 · 목표 |

각 프롬프트에 이 한 줄을 덧붙인다.

```
면의 기준색은 <기준색>이다. 조각들의 밝기는 이 색 주위에서만 움직이고
색상(hue)은 바뀌지 않는다.
```

## 목표치를 이렇게 잡은 근거

같은 키트의 KayKit 아트를 재보면 면 하나의 밝기가 이만큼 움직인다.

| 참조 | 불투명부 표준편차 | 8x8 블록간 편차 |
| --- | --- | --- |
| `KK_Face_Knight` | 49.5 | 43.4 |
| `KK_Icon_ShieldBash` | 43.8 | 35.7 |
| `KK_HFrame_Link_T` | 29.5 | 24.6 |

배경 면은 그 위에 글자와 아이콘이 올라가므로 이보다 훨씬 얕아야 한다.
참조의 1/6 수준인 **3~8**로 잡았다. 0.1~0.6은 아니다.

## 검수

| 항목 | 판정 | 왜 |
| --- | --- | --- |
| **블록간 편차 하한 3.0** | 8x8 블록 평균의 표준편차 ≥ 3.0 | **단색 방지.** 2차가 여기서 걸렸어야 했다 |
| **블록간 편차 상한 8.0** | ≤ 8.0 | 배경이 내용을 방해하지 않게 |
| **국소 대비 상한** | 3x3 표준편차 상위 1% ≤ 2.5 | **잡티 방지.** 1차가 여기서 걸렸어야 했다 |
| 값 범위 | 최대 - 최소가 12 이상 40 이하 | 위 둘의 교차 검증 |
| 네 변 이음매 | 마주 보는 끝 픽셀줄 차이 채널당 ≤ 2 | 반복해도 줄이 안 보이게 |
| 반복 가시성 | 4x4로 이어 붙인 뒤 타일 주기 자기상관 봉우리 없음 | 같은 무늬 재등장 방지 |
| 캔버스 | 정확히 512x512, 불투명 | 격자 규약 |

**하한과 상한을 같이 건다.** 한쪽만 걸면 반대쪽 끝으로 간다 — 두 번 다 그랬다.

검수 코드는 `Tools/UI/verify_kaykit_kit.py`에 있다. 이 항목들을 추가한다.
