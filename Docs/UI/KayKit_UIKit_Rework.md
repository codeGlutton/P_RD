# KayKit UI 키트 — 재작업 요청

받은 41조각을 조립해 본 결과다. **수치는 맞는데 붙지 않는다.**
그리고 그 원인은 조각마다의 실수가 아니라 **생성 방식**에 있다.

| 그룹 | 조각 | 상태 |
| --- | --- | --- |
| F 부품 | `KK_Ring_Portrait`, `KK_Ring_Enemy` | 구멍 356px(기대 352, 오차 4). 깨끗함 |

## 반려 — 21조각

### 1. 이음 단면이 안 맞는다 (프레임 11 + 선택 3 + 바 4)

두께는 규약대로 캔버스의 1/2로 끝난다. 그런데 **그 두께 안의 무늬가 다르다.**
모서리 조각의 팔 단면과, 거기 이어 붙일 이음 조각의 단면을 픽셀로 비교한 결과다.

| 이음 | 16 넘게 어긋난 픽셀줄 | 최대 차이 |
| --- | --- | --- |
| HFrame 위: 모서리 오른쪽 ↔ 이음T 왼쪽 | 17 / 64 | 88 |
| HFrame 아래 | 21 / 64 | 88 |
| HFrame 옆: 모서리 아래 ↔ 이음S 위 | 16 / 64 | 88 |
| LFrame 위 | 7 / 32 | 115 |
| LFrame 옆 | 19 / 32 | 88 |
| **Select: 모서리 ↔ 이음H** | **16 / 32** | **144** |
| **Bar: 마감 ↔ 이음** | **64 / 64** | 57 |

눈으로도 보인다.

- **두꺼운 프레임**: 위/아래 레일은 갈색 나무인데 **옆 레일에는 빨간 띠가 있다.**
  모서리에는 그 빨간 띠가 없다. 세 조각이 서로 다른 몰딩이다.
- **모서리 세로 팔이 옆 레일보다 좁다.** 이어 붙인 자리에 단이 진다.
- **선택 테두리**: 모서리가 이음보다 두껍고, 이음마다 어두운 실선이 보인다.
- **게이지 바**: 마감과 이음의 밝기가 달라 단이 진다.

### 2. 금지한 질감이 들어갔다 (면 3조각)

공통 지시에 이렇게 썼다.

> 텍스처 노이즈·긁힘·오염 없음. 깨끗한 면
> 손그림 붓질 느낌 금지. 사실적 금속 질감 금지. 그런지·러스트 금지

`KK_Fill_Stone`은 **긁힌 자국이 있는 삼각형 얼룩**으로 뒤덮였고,
`KK_Fill_Wood`는 굵은 나뭇결 붓질이다. KayKit은 면이 깨끗하다.

팔레트 검사는 통과했다. 색은 맞는데 **질감이 틀렸다.** 색만 재면 이건 안 걸린다.

### 3. 면이 반복되는 게 보인다

`KK_Fill_Stone`을 4번 이어 붙이면 같은 삼각형 뭉치가 규칙적으로 되돌아온다.
"반복되는 게 보이면 실패"라고 적은 항목이다.

## 원인과 해결

### 왜 단면이 안 맞았나

**조각을 따로따로 생성했기 때문이다.** ImageGen은 앞서 그린 몰딩의 단면을 기억하지
못한다. "A1과 같은 단면"이라고 써도 매번 새로 그린다. 두께는 숫자라서 맞출 수 있지만
단면의 무늬·명암·비드 위치는 말로 못 맞춘다.

지금 방식으로는 몇 번을 다시 뽑아도 안 맞는다. 방식을 바꿔야 한다.

### 해결: 한 장으로 그리고 잘라 쓴다

**프레임 한 세트를 완성된 패널 한 장으로 그린 다음, 격자 경계에서 잘라낸다.**
한 번에 그렸으니 모서리와 레일이 같은 몰딩인 게 보장된다. 자르는 건 코드가 한다.

이건 예전에 빼기로 한 "컨택트 시트"와 다르다. 컨택트 시트는 서로 관계없는 조각을
한 장에 모아 놓은 것이라 잘라 쓰면 경계가 뭉갠다. 이건 **원래 이어져 있는 하나의
몰딩을 이어진 상태로 그리는 것**이고, 자르는 자리가 곧 이어 붙일 자리다.

#### 요청 A — 두꺼운 프레임 원판

```
[그릴 것]
완성된 UI 패널 한 장. 안은 비어 있고 테두리만 있다.

굵게 깎인 나무 테두리(#8B5E3C, 깎인 면 #A9653F)가 사각형을 두르고,
네 모서리에 밝은 회색 금속 브래킷(#C3C7CE)이 덧대어져 있다.
브래킷에는 둥근 리벳 두 개씩. 테두리 직선 구간에는 리벳이
일정한 간격으로 반복된다.

네 변의 몰딩은 완전히 같은 단면이다. 위/아래/좌/우가 같은 굵기,
같은 모따기, 같은 색이다. 빛만 위에서 와서 위쪽이 밝고 아래쪽이 어둡다.
어느 한 변에만 있는 장식(예: 한쪽에만 빨간 띠)은 절대 금지다.

[치수]
캔버스 1024x768, 투명 배경. 패널 테두리는 캔버스를 꽉 채운다.
테두리 띠 두께는 정확히 128px.
모서리 브래킷은 각 구석 256x256px 안에서 끝난다.
직선 구간의 리벳 간격은 정확히 128px이다.
안쪽(테두리를 뺀 가운데)은 완전히 투명하다.

[스타일·팔레트·조명은 공통 지시와 동일]
```

여기서 코드가 잘라낸다.

| 잘라낼 것 | 원판에서의 위치 |
| --- | --- |
| `Corner_T` | (0,0)–(256,256) |
| `Corner_B` | (0,512)–(256,768) |
| `Link_T` | (384,0)–(512,128) ※ 리벳 하나가 가운데 오도록 |
| `Link_B` | (384,640)–(512,768) |
| `Link_S` | (0,320)–(128,448) |

자른 뒤 이음매를 코드가 강제로 맞춘다(양 끝 픽셀줄을 평균내어 덮어씀).
1픽셀 보정이라 그림은 안 바뀌고 타일 줄만 사라진다.

#### 요청 B — 얇은 프레임 원판

같은 지시, 캔버스 512x384, 띠 두께 64px, 모서리 128x128, 리벳 간격 64px.

#### 요청 C — 선택 테두리 원판

```
[그릴 것]
"선택됨"을 알리는 금색 테두리 하나. 안은 완전히 비어 있다.
굵고 균일한 금색 띠 #E8B84B가 사각형을 두른다. 모서리는 둥글게 꺾인다.
띠 위에 이음매·마디·장식이 있으면 안 된다. 처음부터 끝까지 같은 굵기,
같은 색의 매끈한 띠다. 바깥으로 나가는 번짐 금지.

캔버스 512x384, 투명 배경. 띠 두께 정확히 32px.
모서리 곡률은 각 구석 128x128 안에서 끝난다.
```

#### 요청 D — 게이지 바 원판

```
[그릴 것]
가로로 긴 게이지 바 한 개. 왼쪽 70%는 차 있고 오른쪽 30%는 비어 있다.
차 있는 부분은 흰색 계열 단색(#FFFFFF ~ #C8C8C8)의 둥근 원기둥.
빈 부분은 어두운 회색 #6E747E로 안으로 파인 홈.
양 끝은 둥글게 마감된다. 위쪽이 밝고 아래쪽이 어둡다.

캔버스 1024x128, 투명 배경.
막대는 세로 가운데 64px를 차지하고 위아래 32px씩은 투명하다.
막대의 높이와 세로 위치는 왼쪽 끝부터 오른쪽 끝까지 완전히 일정하다.
```

#### 요청 E — 면 3장 다시

```
[추가 지시 — 이번에 틀린 부분]
면은 완전히 깨끗해야 한다. 긁힌 자국, 얼룩, 반점, 붓질, 나뭇결 무늬를
그리지 말 것. 지난번 결과물에는 삼각형 모양의 긁힌 얼룩이 가득했다.

KayKit의 면은 큼직한 다각형이 아주 미세하게 다른 밝기로 이어 붙은
모자이크이고, 그 외의 무늬가 없다. 밝기 차이는 전체 폭의 5% 이내로
아주 은은하다. 멀리서 보면 거의 단색으로 보여야 한다.

반복 확인: 이 이미지를 가로 4번 세로 4번 이어 붙였을 때
"아, 저 무늬가 또 나왔네"라고 알아볼 수 있는 특징이 하나도 없어야 한다.
눈에 띄는 큰 도형, 밝은 점, 어두운 얼룩이 있으면 실패다.
```

## 이번엔 이렇게 검수한다

지난 검수는 **크기·두께·팔레트**만 봤다. 그래서 "두께는 맞는데 무늬가 다른" 것과
"색은 맞는데 질감이 틀린" 것을 놓쳤다. 추가한다.

| 새 항목 | 방법 |
| --- | --- |
| **이음 단면 일치** | 모서리 팔 단면 vs 이음 조각 단면을 픽셀 비교. 16 넘게 어긋난 줄이 전체의 5% 이하 |
| **질감 청결도** | 국소 대비(3x3 표준편차)의 상위 1% 값이 임계 이하. 긁힘·얼룩은 여기서 걸린다 |
| **반복 가시성** | 4x4로 이어 붙인 뒤 자기상관. 타일 주기에 뾰족한 봉우리가 서면 실패 |
| **변별 없는 변** | 프레임 원판의 네 변 몰딩이 서로 같은지(빨간 띠 사고 방지) |

원판에서 잘라내는 방식이라 **이음 단면 일치는 구조적으로 통과한다.**
그래도 검사는 남긴다 — 자르는 좌표를 내가 틀릴 수 있다.
