## 4. 순서

**되돌리기 쉬운 것부터, 확인 가능한 것부터.**

1. **develop 머지** — 파티는 저쪽 것으로. `CombatGameMode.cpp` 만 손으로
2. **빌드·시험** — 여기서 멈추고 확인한다
3. **게임이 어느 HUD 를 쓰는지 확인** — 3.2 의 갈림길
4. **옛 배치안 20장 + 딸린 도구 지우기** — 참조를 먼저 끊는다
5. **`BP/UI` → `UI` 폴더**
6. **옛 전투 HUD 16개** — 3번 결과에 따라
7. **빌드·시험** — 다시 확인

**2번과 7번 사이에는 커밋을 잘게 쪼갠다.** 한 번에 지우면 무엇이 깨뜨렸는지
못 찾는다.
