# KayKit UI 조립 키트 — Codex ImageGen 프롬프트

> 목적: 전투 HUD를 게임 캐릭터 아트(KayKit Adventurers / Skeletons)와 같은 톤으로
> 다시 만든다. 그리고 **조각들이 어긋나지 않게 붙도록** 치수를 미리 못 박는다.
>
> 사용법: 아래 **공통 지시**를 각 조각 프롬프트 앞에 그대로 붙여 하나씩 생성한다.
> 한 이미지에 조각 하나. 여러 조각을 한 장에 모아 그리지 말 것(잘라 쓰면 경계가 뭉갠다).

---

## 왜 다시 만드는가

지금 HUD는 산화 청동 + 검은 석재의 다크 판타지다. 게임 캐릭터는 밝은 저폴리
치비다. 둘이 한 화면에 있으면 UI가 다른 게임에서 붙여넣은 것처럼 보인다.

그리고 조각이 삐져나오는 문제는 **그림 문제가 아니라 치수 문제**다. 지난번 프레임은
그려 놓은 그림을 나중에 재서 썼기 때문에 모서리 비율이 0.312253 같은 값이 나왔고,
그 값을 잘못 쓰면 모서리가 카드를 통째로 덮는다. 이번에는 **치수를 먼저 정하고 그
치수에 맞춰 그리게 한다.** 아래 표의 숫자는 협상 대상이 아니다.

---

## 공통 지시 (모든 프롬프트에 그대로 붙일 것)

```
ImageGen으로 그릴 것. 코드로 도형을 그려서 이미지를 만들지 말 것.

[스타일 — KayKit]
Kay Lousberg의 KayKit 에셋 팩(Adventurers, Skeletons, Dungeon)과 같은 톤.
- 저폴리 3D를 정면에서 렌더한 느낌. 면이 크고 각져 있으며 모서리는 굵게 깎였다
- 재질은 무광 플라스틱/점토. 반사 하이라이트가 거의 없고 면색이 넓게 깔린다
- 부드러운 스튜디오 조명. 그림자는 은은하고 경계가 흐리다
- 밝고 친근한 색. 채도는 높지만 형광은 아니다
- 외곽선(툰 라인) 없음. 텍스처 노이즈·긁힘·오염 없음. 깨끗한 면
- 손그림 붓질 느낌 금지. 사실적 금속 질감 금지. 그런지·러스트 금지

[팔레트 — 이 색만 쓸 것]
석재/금속 밝은 회색  #C3C7CE
석재/금속 중간 회색  #9AA0A9
석재/금속 그늘       #6E747E
가죽 밝은 갈색       #A9653F
가죽 어두운 갈색     #7A4529
나무                 #8B5E3C
빨강 강조            #D2453F
초록                 #3E8E5A
보라                 #6B5CA5
금색 강조            #E8B84B
크림(양피지)         #F2E3C6

[조명]
빛은 항상 왼쪽 위 45도에서 온다. 모든 조각이 같은 방향으로 밝고 어둡다.
위쪽 면이 밝고 아래쪽 면이 어둡다.

[기술 제약 — 이걸 어기면 조각이 안 붙는다]
- 배경 투명 PNG. 배경색을 칠하지 말 것
- 정투영(orthographic) 정면. 원근 기울기 금지
- 조각 바깥으로 나가는 그림자·글로우·번짐 금지.
  조각의 경계 바깥 픽셀은 완전 투명이어야 한다
- 캔버스 크기는 지정된 값 그대로. 여백을 임의로 더하지 말 것
- 워터마크, 설명 글자, 격자 가이드, 치수 표시 금지
- 한 이미지에 조각 하나. 여러 개를 나란히 그린 시트 금지
```

## 치수 규약

조각이 어긋나지 않으려면 **접합면 두께**와 **모서리 비율**이 미리 정해져 있어야 한다.

| 규약 | 값 | 왜 |
| --- | --- | --- |
| 프레임 띠 두께 | 캔버스의 정확히 **3/8** | 모서리 팔과 레일 두께가 같아야 이음매가 안 보인다 |
| 나인슬라이스 모서리 | 캔버스의 정확히 **1/4** | 0.25면 코드에서 반올림 오차가 안 생긴다 |
| 초상화 링 구멍 | 캔버스의 정확히 **11/16** | 초상화가 베젤에 안 먹힌다 |
| 타일 조각 이음매 | 왼쪽 끝 픽셀줄 = 오른쪽 끝 픽셀줄 | 반복시켰을 때 줄이 안 보인다 |

## 파트 목록

### A. 패널 프레임 (5조각으로 사방을 만든다)

좌우는 **좌우 반전**해서 쓰고, 상하는 따로 그린다. 위아래를 회전으로 돌려쓰면
빛 방향이 뒤집혀서 아래쪽 몰딩이 위쪽처럼 밝게 나온다.

| 파일 | 캔버스 | 접합 규칙 |
| --- | --- | --- |
| `KK_Frame_Corner_TL` | 256×256 | 오른쪽 변과 아래쪽 변에서 두께 96px로 끝난다 |
| `KK_Frame_Corner_BL` | 256×256 | 오른쪽 변과 위쪽 변에서 두께 96px로 끝난다 |
| `KK_Frame_Rail_T` | 128×96 | 좌우로 반복. 세로 두께 96px 꽉 참 |
| `KK_Frame_Rail_B` | 128×96 | 좌우로 반복. 세로 두께 96px 꽉 참 |
| `KK_Frame_Rail_L` | 96×128 | 위아래로 반복. 가로 두께 96px 꽉 참 |

**A-1. 위쪽 왼쪽 모서리**
```
[그릴 것]
UI 패널의 왼쪽 위 모서리 장식 한 조각.

굵게 깎인 나무 테두리에 밝은 회색 금속 코너 브래킷이 덧대어져 있다.
브래킷에는 둥근 리벳 두 개가 박혀 있다. 나무는 #8B5E3C, 금속은 #C3C7CE,
그늘진 면은 #9AA0A9.

[치수 — 반드시 지킬 것]
캔버스 256x256, 투명 배경.
장식은 캔버스의 왼쪽 위 구석에 딱 붙는다.
오른쪽 변에서는 가로 띠가 세로 두께 96px로 잘려 끝난다.
아래쪽 변에서는 세로 띠가 가로 두께 96px로 잘려 끝난다.
그 두 끝면은 이어붙일 자리이므로 장식이나 마감선을 두지 말고
평평하게 잘린 단면으로 끝낸다.
```

**A-2. 아래쪽 왼쪽 모서리**
```
A-1과 같은 조각의 아래쪽 왼쪽 버전. 같은 나무 테두리와 금속 브래킷.
빛이 위에서 오므로 A-1보다 전체적으로 어둡고, 윗면이 아니라 아랫면에
그늘이 진다.

캔버스 256x256, 투명 배경.
장식은 왼쪽 아래 구석에 딱 붙는다.
오른쪽 변에서 가로 띠가 세로 두께 96px로, 위쪽 변에서 세로 띠가
가로 두께 96px로 평평하게 잘려 끝난다.
```

**A-3. 위쪽 가로 레일**
```
[그릴 것]
A-1 모서리의 가로 팔과 똑같은 단면의 나무 테두리 한 토막.
가운데에 작은 금속 리벳 하나.

[치수]
캔버스 128x96, 투명 배경.
세로 96px를 위아래 여백 없이 꽉 채운다.
좌우로 무한 반복시킬 것이므로 **왼쪽 끝 픽셀줄과 오른쪽 끝 픽셀줄이
완전히 같아야 한다.** 이어 붙였을 때 세로 줄이 보이면 안 된다.
```

**A-4. 아래쪽 가로 레일** — A-3과 같되 아래쪽 그늘 버전. 캔버스 128×96.

**A-5. 세로 레일**
```
A-3을 90도 돌린 것과 같은 단면. 캔버스 96x128, 투명 배경.
가로 96px를 좌우 여백 없이 꽉 채운다.
위아래로 반복하므로 위 끝 픽셀줄과 아래 끝 픽셀줄이 완전히 같아야 한다.
```

### C. 나인슬라이스 판 (카드 · 버튼 · 강조)

**모두 캔버스 256×256, 모서리 영역은 정확히 64px(=1/4).**
이 1/4 규칙이 이번 키트의 핵심이다. 코드가 모서리 크기를 재지 않고 그냥 쓴다.

| 파일 | 용도 |
| --- | --- |
| `KK_Plate_Card` | 스킬 카드 바닥 |
| `KK_Plate_Button` | 누를 수 있는 버튼 바닥 |
| `KK_Plate_Slot` | 비어 있는 칸(아이콘 소켓) |
| `KK_Plate_Selected` | 선택 강조 테두리 |
| `KK_Plate_Disabled` | 사용 불가 덮개 |

```
[그릴 것 — KK_Plate_Card]
둥근 모서리의 두꺼운 나무 판. 가장자리가 굵게 깎여 있고 위쪽 모서리가 밝다.
나무 #8B5E3C, 깎인 면 #A9653F. 가운데는 평평하고 균일하다.

[치수 — 반드시 지킬 것]
캔버스 256x256, 투명 배경.
판은 캔버스를 꽉 채운다(가장자리에 투명 여백 없음).
**모서리 장식은 각 구석에서 64x64px 안에 완전히 들어가야 한다.**
그 64px 바깥의 가장자리(위/아래/좌/우 가운데 구간)는
좌우 또는 상하로 늘려도 어색하지 않도록 무늬 없이 균일해야 한다.
가운데 128x128 영역은 완전히 평평하고 균일해야 한다.
```

```
[그릴 것 — KK_Plate_Selected]
"이게 선택됨"을 알리는 테두리만. 안쪽은 완전히 비어 있다(투명).
굵고 둥근 금색 띠 #E8B84B가 판 둘레를 두르고, 바깥으로 아주 살짝
따뜻한 빛이 번진다. 번짐은 캔버스 안에서 끝나야 한다.

캔버스 256x256, 투명 배경.
모서리 곡률은 각 구석 64x64px 안에서 끝난다.
변의 가운데 구간은 두께가 일정한 직선 띠여야 한다(늘려 쓸 자리다).
```

```
[그릴 것 — KK_Plate_Disabled]
쓸 수 없는 카드를 덮는 반투명 덮개. 차갑고 어두운 회청색 #6E747E가
불투명도 60% 정도로 깔리고, 가장자리로 갈수록 아주 살짝 진해진다.
무늬·빗금·자물쇠 아이콘 없음. 균일한 덮개면 된다.

캔버스 256x256. 네 구석 64x64px 안에서 모서리가 둥글게 끝난다.
```

### E. 아이콘

**모두 캔버스 256×256, 투명 배경.** 글리프는 캔버스 안쪽 **192×192** 안에 들어가고
바깥 32px은 여백이다. 이렇게 해야 어느 판에 얹어도 테두리에 안 닿는다.

캐릭터 아트와 같은 저폴리 3D 오브젝트를 정면에서 본 모습으로 그린다.
평면 픽토그램이 아니다.

| 파일 | 그릴 것 |
| --- | --- |
| `KK_Icon_Move` | 갈색 가죽 부츠 한 짝 |
| `KK_Icon_BasicAttack` | 회색 저폴리 검 두 자루가 X자로 교차 |
| `KK_Icon_ShieldBash` | 빨강·흰색 방패가 앞으로 밀려 나오는 모습 |
| `KK_Icon_PinSlash` | 검 한 자루가 아래로 꽂힌 모습 |
| `KK_Icon_Breakthrough` | 방패가 쪼개지고 그 사이로 검이 지나간 모습 |
| `KK_Icon_Riposte` | 방패를 세우고 검을 뒤로 당긴 방어 자세 |
| `KK_Icon_EndTurn` | 나무틀 모래시계 |
| `KK_Icon_Objective` | 빨간 깃발 |
| `KK_Icon_Map` | 말린 양피지 지도 |
| `KK_Icon_Inventory` | 갈색 가죽 배낭 |
| `KK_Icon_Settings` | 회색 금속 톱니바퀴 |
| `KK_Icon_Skills` | 펼쳐진 책 |

각 아이콘 프롬프트는 이렇게 마무리한다.

```
캔버스 256x256, 투명 배경.
물체는 가운데 192x192 안에 완전히 들어가고 바깥 32px은 비워 둔다.
물체가 캔버스 변에 닿거나 잘리면 안 된다.
바닥 그림자를 그리지 말 것.
```

## 받고 나서 검수할 것

받은 조각은 붙여 보기 전에 아래를 기계로 확인한다. 눈으로 보면 통과시켜 버린다.

| 항목 | 판정 |
| --- | --- |
| 캔버스 크기 | 지정 값과 정확히 일치 |
| 바깥 여백 | 프레임/판 조각은 지정한 변에 알파가 0인 줄이 없어야 함 |
| 타일 이음매 | 양 끝 픽셀줄의 차이가 채널당 2 이하 |
| 접합 두께 | 모서리 조각이 접합면에서 96px 두께로 끝나는지 |
| 나인슬라이스 | 가운데 128×128 구간의 표준편차가 낮은지(균일해야 늘려도 됨) |
| 젬 On/Off | 두 장의 알파 마스크가 동일한지 |
| 아이콘 여백 | 알파 바운딩 박스가 192×192 안에 들어가는지 |
| 팔레트 | 지정 색 11개에서 벗어난 색이 몇 %인지 |

**한 항목이라도 틀리면 그 조각만 다시 뽑는다.** 이번에는 그림을 재서 코드를 맞추지
않는다. 코드가 위 숫자를 그대로 쓰고, 안 맞는 그림을 되돌려 보낸다.

## 이 키트가 들어오면 바뀌는 것

배치안 10개는 그대로 두고 `Tools/UI/combat_layout_kit.py`의 팔레트와 파트 경로만
갈아 끼운다. 배치는 배치대로 이미 평가할 수 있고, 톤은 톤대로 따로 갈린다.

바뀌는 상수는 이것뿐이다.

- `FRAME_GOLD` → KayKit 나무/금속 색
- `SURFACE_TINT`, `CARD_INK` → 밝은 쪽으로
- `CORNER_*`, `SELECT_MARGIN` → 위 규약값 (0.25 고정)
- `C04` 경로 → KayKit 경로
