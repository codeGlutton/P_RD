# KayKit UI 조립 키트 — Codex ImageGen 프롬프트

> 목적: 전투 HUD를 게임 캐릭터 아트(KayKit Adventurers / Skeletons) 톤으로 다시
> 만든다. 그리고 **조각을 최대한 잘게 쪼개서**, 어떤 크기의 패널이든 조각을
> 이어 붙여 만들 수 있게 한다.
>
> 사용법: 아래 **공통 지시**를 각 조각 프롬프트 앞에 그대로 붙여 하나씩 생성한다.
> 한 이미지에 조각 하나. 여러 조각을 한 장에 모아 그리지 말 것(잘라 쓰면 경계가 뭉갠다).

---

## 왜 쪼개는가

지금 HUD가 삐져나오는 건 그림 문제가 아니다. **한 장짜리 그림을 늘려 쓰기 때문**이다.

한 장을 늘려 쓰면 "어디까지가 모서리이고 어디부터 늘려도 되는가"를 누군가 재야
한다. 지난번엔 그렇게 재서 `0.312253` 같은 값이 나왔고, 그 값을 잘못 쓰니까 선택
테두리가 카드를 통째로 삼켰다. 재는 순간 틀릴 수 있다.

**조각을 이어 붙이면 잴 일이 없다.** 모서리는 모서리 크기 그대로 놓고, 사이는 이음
조각을 필요한 개수만큼 반복한다. 남는 자리가 생기면 조각 하나를 더 놓거나 덜 놓으면
된다. 늘리지 않으니 뭉개지지도 않는다.

그러려면 **모든 조각이 같은 격자에 맞아야 한다.** 아래 격자 규약이 이 문서의 전부다.

---

## 격자 규약

기본 단위 **1U = 32px** (화면에 그려질 크기). 그림은 4배로 그린다 → **1U = 128px 캔버스**.

모든 조각의 캔버스는 U의 배수다. 모든 이음매는 U 경계에서 만난다.
그래서 조립이 자로 재는 일이 아니라 **덧셈**이 된다.

| 쓰임 | 조각 크기 | 캔버스 |
| --- | --- | --- |
| 두꺼운 프레임 모서리 | 2U × 2U | 256×256 |
| 두꺼운 프레임 이음 | 1U × 1U | 128×128 |
| 얇은 프레임 모서리 | 1U × 1U | 128×128 |
| 얇은 프레임 이음 | 0.5U × 0.5U | 64×64 |
| 면(바닥) | 4U × 4U | 512×512 |
| 아이콘 | 2U × 2U | 256×256 |

**띠 두께**는 그 조각 캔버스의 정확히 **1/2**이다. 두꺼운 프레임은 1U(=32px),
얇은 프레임은 0.5U(=16px). 이 값 하나로 모서리 팔과 이음 조각이 맞물린다.

예: 가로 320px 패널의 위쪽 테두리
= 모서리(64) + 이음 32px짜리 **6개** + 모서리(64) = 320. 딱 맞는다.

```

## A. 두꺼운 프레임 (큰 패널용, 띠 1U = 32px)

이 6조각으로 **어떤 크기의 사각 패널이든** 테두리를 만든다.
좌우는 좌우 반전해 쓰고, 위아래는 빛 방향이 달라서 따로 그린다.

| # | 파일 | 캔버스 | 이음면 |
| --- | --- | --- | --- |
| A1 | `KK_HFrame_Corner_T` | 256×256 | 오른쪽 변, 아래쪽 변 |
| A2 | `KK_HFrame_Corner_B` | 256×256 | 오른쪽 변, 위쪽 변 |
| A3 | `KK_HFrame_Link_T` | 128×128 | 왼쪽 변, 오른쪽 변 (가로 반복) |
| A4 | `KK_HFrame_Link_B` | 128×128 | 왼쪽 변, 오른쪽 변 (가로 반복) |
| A5 | `KK_HFrame_Link_S` | 128×128 | 위쪽 변, 아래쪽 변 (세로 반복) |
| A6 | `KK_HFrame_Joint` | 128×128 | 네 변 모두 (T자·십자 이음) |

**A1 — 위쪽 모서리**
```
[그릴 것]
UI 패널의 왼쪽 위 모서리. 굵게 깎인 나무 테두리 위에 밝은 회색 금속
코너 브래킷이 덧대어져 있고, 브래킷에 둥근 리벳 두 개가 박혀 있다.
나무 #8B5E3C, 깎인 면 #A9653F, 금속 #C3C7CE, 금속 그늘 #9AA0A9.

[치수]
캔버스 256x256, 투명 배경.
테두리 띠의 두께는 정확히 128px (캔버스의 절반).
장식은 왼쪽 위 구석에 딱 붙는다.
오른쪽 변: 가로 띠가 세로 두께 128px로 평평하게 잘려 끝난다.
아래쪽 변: 세로 띠가 가로 두께 128px로 평평하게 잘려 끝난다.
두 이음면에는 마감선이나 둥근 처리를 두지 말 것. 잘린 단면 그대로.
```

**A2 — 아래쪽 모서리**
```
A1과 완전히 같은 나무 테두리와 금속 브래킷. 아래쪽 왼쪽 버전이다.
빛이 위에서 오므로 A1보다 전체가 어둡고, 그늘이 윗면이 아니라 아랫면에 진다.
띠 두께·모따기 폭·리벳 크기는 A1과 1px도 다르면 안 된다.

캔버스 256x256, 투명 배경. 띠 두께 128px.
장식은 왼쪽 아래 구석에 딱 붙는다.
오른쪽 변에서 가로 띠가, 위쪽 변에서 세로 띠가 각각 128px 두께로
평평하게 잘려 끝난다.
```

**A3 — 위쪽 이음**
```
[그릴 것]
A1 모서리의 가로 팔과 똑같은 단면의 나무 테두리 한 토막.
가운데에 작은 금속 리벳 하나.

[치수]
캔버스 128x128, 투명 배경.
띠는 캔버스 **위쪽 절반 128x64를 꽉 채우고**, 아래쪽 절반은 완전 투명이다.
좌우로 무한히 이어 붙일 것이므로 왼쪽 끝 픽셀줄과 오른쪽 끝 픽셀줄이
완전히 같아야 한다. 이어 붙였을 때 세로 줄이 보이면 실패다.
A1의 가로 팔 단면과 높이·색·모따기가 정확히 일치해야 한다.
```

**A4 — 아래쪽 이음** — A3와 같되 아래쪽 그늘 버전. 띠가 캔버스 **아래쪽 절반**을 채운다.

**A5 — 옆 이음**
```
A3를 세로로 세운 것과 같은 단면. 캔버스 128x128, 투명 배경.
띠는 캔버스 **왼쪽 절반 64x128을 꽉 채우고** 오른쪽 절반은 완전 투명이다.
위아래로 이어 붙이므로 위 끝 픽셀줄과 아래 끝 픽셀줄이 완전히 같아야 한다.
```

**A6 — 십자 이음**
```
가로 띠와 세로 띠가 만나는 자리를 덮는 조각. 패널을 칸으로 나눌 때 쓴다.
A3와 A5가 십자로 교차하고, 교차점에 금속 리벳 하나.

캔버스 128x128, 투명 배경.
가로 띠는 세로 가운데 64px, 세로 띠는 가로 가운데 64px를 차지한다.
네 변 모두 이음면이다. 각 변에서 띠가 평평하게 잘려 끝난다.
```

| D3 | `KK_Select_Link_V` | 64×64 | 위쪽, 아래쪽 |

```
[그릴 것 — KK_Select_Corner]
"이게 선택됨"을 알리는 굵은 금색 띠의 모서리 한 귀퉁이.
금색 #E8B84B, 안쪽으로 살짝 밝은 심. 안쪽 영역은 완전히 투명하다.

## 받고 나서 검수할 것

받은 조각은 붙여 보기 전에 아래를 기계로 확인한다. 눈으로 보면 통과시켜 버린다.

| 항목 | 판정 |
| --- | --- |
| 캔버스 크기 | 표의 값과 정확히 일치 |
| 이음면 여백 | 이음면으로 지정한 변에 알파 0인 픽셀줄이 없어야 함 |
| 이음면 두께 | 그 변에서 불투명 구간이 정확히 캔버스의 1/2 |
| 타일 이음매 | 마주 보는 두 끝 픽셀줄의 차이가 채널당 2 이하 |
| 그룹 내 일치 | 같은 그룹 조각들의 띠 두께가 서로 1px 이내 |
| 젬 On/Off | 두 장의 알파 마스크가 완전히 동일 |
| 바 4종 | 막대의 세로 위치·높이가 네 장 모두 동일 |
| 링 구멍 | 투명 원의 지름이 캔버스의 11/16 ± 2px |
| 아이콘 여백 | 알파 바운딩 박스가 가운데 192×192 안 |

## 이 키트가 들어오면 코드에서 바뀌는 것

배치안 10개는 그대로 둔다. `Tools/UI/combat_layout_kit.py`의 조립 함수만 바꾼다.

지금은 `frame()`이 모서리 4개 + 레일 4개를 놓고 레일을 **늘린다**.
새 방식은 모서리 4개 + 이음 조각 **N개**를 놓는다. N은 나눗셈으로 나온다.

```
N = (패널 폭 - 모서리 폭 x 2) / 32
```

나눠떨어지지 않으면 패널 폭을 32의 배수로 맞춘다. 조각을 반쪽 늘리는 것보다
패널을 2px 키우는 게 낫다. 이 규칙 하나로 "삐져나옴"이 구조적으로 사라진다.

`SELECT_MARGIN`, `CORNER_RATIO`, `BAND_MIN` 같은 **재서 얻은 상수는 전부 사라진다.**
남는 건 `UNIT = 32` 하나다.
