# KayKit UI 키트 2차 — 시안 1과 구현의 차이를 메우는 조각

시안 1(KayKit 톤 목업)대로 1안을 다시 짰다. 배치·색·프레임은 맞췄고, **남은
차이는 전부 없는 그림 때문**이다. 이 문서는 그 그림 목록이다.

1차 41조각의 규약을 그대로 따른다 — 격자 1U = 32px, 그림은 4배, 투명 PNG,
정투영 정면, 조각 바깥 픽셀은 완전 투명.

---

## 왜 이것들인가

| 시안 | 지금 | 필요한 것 |
| --- | --- | --- |
| 아군 행에 기사·궁수·마법사 얼굴 | 기사만 있고 둘은 빈 링 | 초상화 3종 |
| 적 패널에 독수리 얼굴 | 거미 그림을 대신 씀 | 독수리 초상화 |
| 턴 순서 5칸에 얼굴 | 빈 링 5개 | 위 4종을 그대로 재사용 |
| `☠ 중독 2턴` 뱃지 | 글자만 (지금은 빔) | 상태이상 아이콘 |
| `🛡 방어 0`, `⚔ 예상 피해 8~14` | 글자만 | 작은 정보 아이콘 2종 |

초상화는 **원형 링 안에 끼우는 그림**이라 링 구멍(캔버스의 11/16)에 맞아야
한다. 그래서 크기 규약이 따로 있다.

## A. 초상화 4종

**캔버스 256×256(=8U), 투명 배경.**

원형 금속 링 안에 끼워 넣는다. 링의 구멍은 캔버스의 11/16이므로, **얼굴은
가운데 지름 176px 원 안에 완전히 들어가야 한다.** 그 원 밖은 링이 덮으므로
그려도 안 보인다.

| 파일 | 누구 |
| --- | --- |
| `KK_Face_Knight` | 기사 |
| `KK_Face_Archer` | 궁수 |
| `KK_Face_Mage` | 마법사 |
| `KK_Face_Eagle` | 독수리 (적) |

```
[그릴 것 — KK_Face_Knight]
KayKit Adventurers의 기사 캐릭터를 정면에서 본 얼굴과 어깨.
치비 비율의 큰 머리, 단순한 이목구비, 갈색 짧은 머리.
회색 판금 어깨와 목가리개가 아래쪽에 살짝 보인다.
피부 #F0C8A0, 갑옷 #C3C7CE, 그늘 #9AA0A9.

[치수]
캔버스 256x256, 투명 배경.
얼굴과 어깨는 캔버스 가운데 지름 176px 원 안에 완전히 들어간다.
그 원 밖에는 아무것도 그리지 않는다(완전 투명).
머리 꼭대기와 어깨 아래가 그 원에 살짝 닿을 만큼 크게 그린다.
목 아래를 잘라내는 원형 크롭이나 테두리를 그리지 말 것 -- 테는 코드가 얹는다.
```

- `KK_Face_Archer` — 초록 후드와 튜닉, 갈색 묶은 머리. 초록 #3E8E5A
- `KK_Face_Mage` — 파란 뾰족 모자와 로브, 갈색 긴 머리. 모자가 원을 넘지 않게
  **모자 끝을 접거나 기울여서** 176px 원 안에 넣을 것
- `KK_Face_Eagle` — 흰머리수리의 머리. 흰 머리, 노란 부리, 갈색 몸.
  적이므로 눈매가 사납다

## B. 상태·정보 아이콘 3종

**캔버스 64×64(=2U), 투명 배경.** 글리프는 가운데 48×48 안에.

작은 글씨 옆에 붙는 아이콘이라 1차 아이콘(256×256)보다 훨씬 작게 그려진다.
**형태가 단순해야 한다** — 16~20px로 줄었을 때 뭉치면 못 쓴다.

| 파일 | 그릴 것 |
| --- | --- |
| `KK_Tag_Poison` | 보라색 해골. 중독 표시 |
| `KK_Tag_Defense` | 회색 방패 하나 |
| `KK_Tag_Damage` | 회색 검 한 자루, 날이 위를 향함 |

```
[그릴 것 — KK_Tag_Poison]
보라색 작은 해골 하나. 정면. 눈구멍 두 개와 코 구멍만.
보라 #6B5CA5, 밝은 면 #8B7CC5.

[치수]
캔버스 64x64, 투명 배경.
해골은 가운데 48x48 안에 완전히 들어간다.
20픽셀로 줄여도 해골인 게 읽혀야 한다. 이빨·금·장식 같은 잔무늬를 넣지 말 것.
윤곽이 단순한 덩어리 하나로 보이는 게 맞다.
```

`KK_Tag_Defense`와 `KK_Tag_Damage`도 같은 규칙. 손잡이 장식, 리벳, 문양 없이
실루엣만.

## C. 받고 나서 검수할 것

1차와 같은 스크립트(`Tools/UI/verify_kaykit_kit.py`)에 항목을 더한다.

| 항목 | 판정 |
| --- | --- |
| 캔버스 크기 | 초상화 256×256, 태그 64×64 |
| 초상화 여백 | 알파 바운딩 박스가 가운데 지름 176px 원 안 |
| 태그 여백 | 알파 바운딩 박스가 가운데 48×48 안 |
| 축소 가독성 | 태그를 20px로 줄인 뒤 알파 덩어리가 하나로 유지되는지 |
| 팔레트 | 지정 색에서 벗어난 픽셀 비율 |
| 네 얼굴의 크기 일관성 | 네 장의 알파 바운딩 박스 높이가 서로 10% 이내 |

마지막 항목이 중요하다. 초상화 넷의 얼굴 크기가 제각각이면 아군 행 세 개가
줄이 안 맞는다. **네 장을 한 벌로 보고 크기를 맞춰야 한다.**
