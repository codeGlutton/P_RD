# KayKit 톤 전투 HUD 11~20안 — Codex ImageGen 프롬프트

> 1~10안은 배치의 왕도(상하 띠·좌우 열·방사형·카드 핸드…)를 훑었다.
> 11~20안은 **아직 안 건드린 축**을 판다: 엄지 인체공학, 턴 순서 중심 사고,
> 조작 흐름의 역전(대상 먼저), 접었다 펴는 UI, 화면 자체를 가구로 쓰는 프레임.
>
> 사용법: 아래 **공통 지시**를 각 안 앞에 붙여 한 장씩 생성한다.
> 열 장이 같은 전투·같은 수치여야 배치만 비교된다.

## 공통 지시 (열 개 프롬프트 앞에 그대로 붙일 것)

```
ImageGen으로 그릴 것. 코드로 도형을 그려서 이미지를 만들지 말 것.

[캔버스]
1920 x 1080, 가로 모바일 게임 화면. UI 목업 한 장.

[게임]
그리드 기반 턴제 전술 RPG (SRPG). 로그라이크. 한국어 UI.
플레이어는 용병 3명을 조작한다. 주사위는 없다.

[미술 스타일 — KayKit]
Kay Lousberg의 KayKit 에셋 팩(Adventurers, Skeletons, Dungeon)과 같은 톤.
- 저폴리 3D를 정면에서 렌더한 느낌. 면이 크고 각져 있으며 모서리는 굵게 깎였다
- 재질은 무광 플라스틱/점토. 반사 하이라이트가 거의 없고 면색이 넓게 깔린다

  어두운 윤곽이 있어 화면에 단단히 고정돼 보인다
- 밝고 친근한 색. 채도는 높지만 형광은 아니다. 회색 섞인 파스텔 금지
- 외곽선(툰 라인) 없음. 노이즈·긁힘·오염 없음. 깨끗한 면
- 손그림 붓질 느낌 금지. 사실적 금속 질감 금지. 그런지·러스트 금지

[배경]

기사·궁수·마법사(아군 3명)와 독수리 2마리(적). 나무통, 상자, 바위 같은

5. 턴 종료 버튼
6. 선택된 적: 독수리 HP 50/50, 방어 0, 예상 피해 8~14
7. 목표: "모든 적 처치 — 남은 적 2"

네온 글로우, 원형/부채꼴 진행 게이지, 패널 밖으로 흐르는 리본 장식

[하지 말 것]
- 주사위 요소 일절 금지. 마나/스태미나 등 AP 외 자원 금지
- 영어 UI 텍스트 금지 (ROUND 1 은 예외)
- 워터마크, 설명 캡션, 격자 가이드라인 금지

[모바일 제약]

- 화면 하단 양쪽 모서리가 엄지가 닿기 쉬운 자리

## 11안 — 양손 엄지 클러스터

```
[배치]
가로 폰을 두 손으로 쥔 자세에서 두 엄지가 닿는 자리에 조작을 모은다.

왼쪽 아래 구석: 아군 3명 카드가 세로로 촘촘히. 구석에 가까울수록 크다
              (기사가 맨 아래, 가장 크고 강조).
오른쪽 아래 구석: 명령 6칸이 2열 3행 격자로. 엄지 반경 안에 전부 들어온다.
                턴 종료 버튼은 그 격자 바로 위.
상단: 왼쪽 ROUND 1, 중앙 턴 순서, 오른쪽 목표 — 읽기 전용 정보만 위로.
적 정보: 오른쪽 위, 목표 아래 붉은 패널.

중앙 하단이 완전히 비어 캐릭터가 안 가려진다. 조작이 전부 엄지 반경 안.
```

## 12안 — 턴 타임라인 중심

```
[배치]
왼쪽 가장자리 전체를 세로 턴 타임라인이 차지한다. 이 게임의 주인공은
"다음에 누가 움직이는가"라는 주장.

왼쪽 세로 열: 위에서 아래로 기사(현재, 큰 카드) → 독수리 → 궁수 → 독수리
             → 마법사. 아군 칸에는 HP·AP까지, 적 칸에는 HP만.
             현재 차례 카드가 가장 크고 오른쪽으로 튀어나온다.
             칸 사이에 아래 방향 화살표.
하단 중앙~오른쪽: 명령 카드 6장 가로 배열.
오른쪽 위: 목표. 왼쪽 위(타임라인 위): ROUND 1.
적 상세: 오른쪽 아래, 명령 카드 위 붉은 패널. 턴 종료는 오른쪽 맨 아래.

아군 패널과 턴 순서가 하나로 합쳐져 중복이 없다.
```

## 13안 — 우측 세로 커맨드 레일

```
[배치]
명령 6칸을 화면 오른쪽 가장자리에 세로로 쌓는다. 오른손 엄지가 위아래로
쓸어내리며 고른다.

오른쪽 세로 레일: 명령 6칸 세로 배열. 각 칸은 가로로 긴 띠(아이콘 왼쪽,
                이름·수치 오른쪽). 방패 강타가 금색 강조.
                레일 맨 아래에 턴 종료 버튼.
왼쪽 아래: 아군 3명 가로 칩 (초상+HP+AP만 컴팩트).
상단: 왼쪽 ROUND 1, 중앙 턴 순서, 오른쪽 목표.
적 정보: 왼쪽 위, ROUND 1 아래 붉은 패널 (오른쪽은 레일이 차지하므로).

2안(좌측 세로 파티)의 거울상이되, 세로로 쌓는 것이 파티가 아니라 명령이다.
```

## 14안 — 유닛 머리 위 인라인 바

```
[배치]
HUD를 화면 가장자리에서 떼어 전장 안으로 넣는다. 4안(방사형)과 달리
원이 아니라 캐릭터 머리 위 가로 스트립이다.

전장의 기사 캐릭터 머리 위: 작은 가로 명령 바. 아이콘 6개가 한 줄로 붙어
    있고 각 아이콘 아래 AP 비용만 작게. 방패 강타 금색 강조.
    바 전체는 작은 금속 패널 하나로 묶여 있다.
기사 발밑: 선택 타일 강조.
왼쪽 아래: 아군 3명 가로 칩 (초상+HP 바만).
오른쪽 아래: 턴 종료. 상단: ROUND 1 / 턴 순서 / 목표 최소 크기.
적 정보: 독수리 옆에 작은 말풍선 패널로 (HP·예상 피해만).

시선이 캐릭터에서 안 떠난다. 명령 바가 전장을 가리는 정도가 관건.
```

## 15안 — 하단 서랍 (펼친 상태)

```
[배치]
평시에는 하단에 얇은 손잡이 탭만 있고, 위로 쓸어올리면 서랍이 펼쳐진다.
이 목업은 서랍이 펼쳐진 순간이다.

하단 서랍(화면 하단 1/3): 나무 프레임의 큰 판 하나가 아래에서 올라와 있다.
    왼쪽에 아군 3명 세로 목록, 중앙에 명령 카드 6장, 오른쪽에 적 상세와
    턴 종료. 서랍 위 가장자리 중앙에 아래로 접는 손잡이(둥근 탭)가 보인다.
서랍에 가려진 전장은 위쪽 2/3만 보인다.
상단: ROUND 1 / 턴 순서 / 목표 얇게.

5안(통합 바)과 비슷하지만 "접을 수 있다"는 손잡이가 명시적이다.
```

## 16안 — 보드게임 테이블 프레임

```
[배치]
화면 네 변을 얇은 나무 테이블 가장자리가 둘러 전장이 보드게임판처럼 보인다.
정보가 그 나무 프레임 위에 "새겨져" 있다.

위 프레임 띠: 왼쪽에 ROUND 1, 중앙에 턴 순서(작은 원형 초상 5개), 오른쪽에
             목표 -- 전부 나무 띠 위에 직접 얹힌다. 별도 패널 없음.
아래 프레임 띠(더 두껍다): 왼쪽에 아군 3명 칩, 중앙에 명령 6칸, 오른쪽에
             턴 종료 -- 역시 띠 위에 직접.
좌우 프레임 띠는 얇고 비어 있다.
적 정보: 오른쪽 위 구석, 프레임 안쪽에 살짝 겹치는 붉은 패널 하나만 예외.

패널이 거의 없어져 UI가 "가구"가 된다. 정보 밀도는 낮다.
```

## 17안 — 대상 우선 흐름

```
[배치]
조작 순서를 뒤집는다: 적을 먼저 고르면 그 적 카드에 스킬이 붙는다.
이 목업은 독수리를 고른 상태다.

오른쪽 1/3: 큰 적 카드. 독수리 초상화(크게), HP 50/50 바, 방어 0,
    예상 피해 8~14. 그 카드 안쪽 아래에 명령 6칸이 2열 3행으로 들어있다 --
    "이 대상에게 무엇을 할까"로 읽힌다. 방패 강타 금색 강조.
왼쪽 아래: 아군 3명 세로 카드 (기사 강조).
상단: ROUND 1 / 턴 순서 / 목표.
턴 종료: 오른쪽 맨 아래, 적 카드 밖.

스킬이 대상 문맥 안에 있어 오조작이 줄어든다. 카드가 커서 전장을 가린다.
```

## 18안 — 코너 부채 (쿼터 팬)

```
[배치]
4안의 방사형을 코너로 옮긴다. 오른쪽 아래 구석을 중심으로 명령 6칸이
1/4 부채꼴 호를 그리며 펼쳐진다.

오른쪽 아래 구석: 턴 종료 버튼(부채의 중심축). 그 위로 명령 카드 6장이
    호를 따라 계단식으로 -- 구석에서 가까운 카드가 크고, 호 바깥으로 갈수록
    작아진다. 방패 강타 금색 강조. 카드는 전부 같은 사각 모양(회전만 살짝).
왼쪽 아래: 아군 3명 세로 카드.
상단: ROUND 1 / 턴 순서 / 목표. 적 정보: 오른쪽 위 붉은 패널.

오른손 엄지 호와 카드 호가 일치한다. 4안보다 전장 가림이 적다.
```

## 19안 — 상단 명령 바 (역전)

```
[배치]
통념을 뒤집어 명령을 화면 위에 둔다. 태블릿을 거치해 두고 검지로 조작하는
자세, 또는 "캐릭터를 절대 가리지 않는 HUD"라는 주장.

상단 띠: 명령 카드 6장이 한 줄로 화면 위 중앙을 차지한다. 카드는 아래로
    늘어진 형태(위쪽이 프레임에 물려 있다). 방패 강타 금색 강조.
    왼쪽 끝 ROUND 1, 오른쪽 끝 턴 종료.
하단 왼쪽: 아군 3명 가로 칩. 하단 중앙: 턴 순서. 하단 오른쪽: 적 정보 + 목표.

읽는 것(파티·턴·적)이 아래, 누르는 것(스킬)이 위 -- 9안의 정반대.
하단 캐릭터 가림이 0이 되는 대신 엄지 도달성을 버린다.
```

## 20안 — 지휘관 모드 (전술 오버레이)

```
[배치]
평시 HUD는 거의 없고, "지휘 모드" 버튼을 누르면 시간이 멈추며 전장 전체에
전술 정보가 덧그려진다. 이 목업은 지휘 모드가 켜진 순간이다.

전장 위에 직접:
- 각 유닛 발밑에 진영색 타일 테두리 (아군 파랑, 적 빨강)
- 각 유닛 머리 위에 이름표+HP 바+AP 보석 (평시보다 큰 판)
- 독수리 옆에 예상 피해 8~14 태그
- 기사에서 독수리로 향하는 이동 경로 화살표 (점선 화살표)
화면 가장자리:
