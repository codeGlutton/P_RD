> 이전 발주 방식(글로 쓴 스펙 → 생성 → 절대값 검수)을 **폐기**한다.
> 네 번의 발주에서 결과물이 스펙 수치는 통과하면서도 시안과 계속 멀어졌다.
> 원인은 구조다: **검수 기준 어디에도 "시안"이 없었다.**
>
> 이번 방식: **승인된 시안 이미지를 부위별로 분해**해서, 각 부품을 시안

> 거리로 잰다. 형용사 게이트("단단하게", "재질감 있게")는 전부 없앤다.

## 제작 방법 — 부품별로 지정

**1. 면 텍스처 6종: 시안에서 직접 추출**
해당 구역에서 글자·아이콘이 없는 면 부분을 크롭 → 512×512로 확장(참조 기반
아웃페인팅 또는 재생성) → 타일러블 보정. 색·밀도·결이 시안 그대로여야 하며,
"더 멋지게" 만들지 말 것. 시안의 면은 은은하다 — 그게 정답이다.

**2. 프레임 원판 4장 + 버튼 2장: 시안 크롭을 참조 이미지로 재생성**
시안의 프레임은 작게 그려져 있으므로 그대로 잘라 쓸 수 없다. 해당 구역
크롭을 참조로 첨부하고 "이 테두리와 같은 재질·색·명암 구조를 1024×768
원판 규격으로" 재생성한다. **참조와 다른 창작(더 강한 대비, 더 화려한 장식,
더 깊은 요철)을 금지한다.** 규격은 기존과 동일:
- 두꺼운 1024×768 띠 128px / 얇은 512×384 띠 64px / 버튼 1024×256
- 절단 좌표·파일명 기존 그대로 (코드 무수정 덮어쓰기)

**3. 소품(링·젬·배지·태그·선택 테두리): 시안 크롭 참조 재생성**
캔버스·투명 규격은 기존 조각과 동일. 시안에서 해당 소품이 보이는 크롭을
참조로 준다. 알파 일치 규칙(젬 On/Off, 버튼 Up/Down) 유지.

## 검수 — 전부 시안 상대값

| 항목 | 판정 |
| --- | --- |
| **색 거리** | 부품 평균색 vs 대응 시안 크롭 평균색, **채널당 ≤ 15** |
| **채도 거리** | 부품 채도 vs 시안 크롭 채도, **±0.08** |
| **대비 거리** | 부품 내부 표준편차가 시안 크롭의 **0.7~1.4배** |
| 기하 | 기존 검사 유지 (캔버스·절단 이음 0·타일 무결성·알파 일치) |

절대값 게이트(윤곽≤70, 스펙큘러≥230 등)는 **전부 삭제**한다. 시안이 그렇게
안 생겼는데 그 수치를 통과시키는 게 지금까지의 사고였다.

## 이 발주가 끝나면 코드에서 바뀌는 것 (내 몫)

지금 걸려 있는 보정 곱색(`SURFACES` 틴트, `FRAME_TINTS`)을 **전부 흰색으로
되돌린다.** 부품이 시안 색을 직접 가지므로 코드는 더 이상 색을 만지지
않는다. 배치·절단·조립 코드는 무수정.
