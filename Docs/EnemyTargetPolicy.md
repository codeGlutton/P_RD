# 몬스터 공격 대상 설정

## 설정 위치

몬스터 스폰 DA (`/Game/BP/DataAsset/Unit/EnemyUnit/...`)를 열고 **AI → Target Policy**를 펼칩니다.

- **Priority**: 누구를 노릴지
- **When Target Unreachable**: 우선 대상을 이번 턴에 공격할 수 없을 때 행동
- **Status Tag**: 상태이상 기준일 때 비교할 태그

기존 DA의 기본값은 `Nearest + Attack Available Target`입니다. 기존 자산을 재저장할 필요는 없습니다.
실제 몬스터의 밸런스 설정은 변경하지 않았으므로, 원하는 몬스터 DA에서 선택해 저장해야 새 성향이 적용됩니다.

## 우선순위

| Priority | 의미 |
| --- | --- |
| Nearest | 현재 위치에서 경로 거리가 가장 가까운 용병 |
| Lowest HP | 현재 HP가 가장 낮은 용병 |
| Lowest HP Percent | 현재 HP / 최대 HP가 가장 낮은 용병 |
| Highest Max HP | 최대 HP가 가장 높은 용병 |
| Farthest | 경로 거리가 가장 먼 용병. 경로가 없는 용병은 후순위 |
| Random | 룸 이벤트 시드에 따른 무작위 용병 |
| With Status | Status Tag가 있는 용병 우선 |
| Without Status | Status Tag가 없는 용병 우선 |
| Most Targets | 이동/AP/조준/영향 범위 및 페이즈별 팀 필터를 고려해 가장 많은 용병을 범위에 넣는 위치 |

능력치·태그 조건이 같으면 가까운 용병, 거리까지 같으면 시드 추첨으로 정합니다.
상태이상 조건에 맞는 용병이 없으면 나머지 후보 중 가까운 용병을 고릅니다.
상태 태그를 비워 두면 에셋 검증에서 오류를 표시하고, 실행 중에는 거리 기준으로 안전하게 처리합니다.
사망 태그가 있는 용병과 null은 제외합니다.

`Most Targets`는 빈 칸 조준과 자기 중심 광역도 평가합니다. 연타에 중복 포함된 용병은 한 명으로 셉니다.
명중 인원이 같은 이동 위치는 기존 MoveTendency를 따릅니다. 예상 피해량·면역·효과별 확률을 평가하는 기능은 아닙니다.
이 모드는 특정 한 명을 추격하지 않으므로 When Target Unreachable 항목이 숨겨집니다.
지금 범위에 넣을 대상이 없으면 가까운 용병을 기준으로 이동합니다.

## 공격 불가 시 행동

- **Attack Available Target**: 이번 턴에 이동 후 공격할 수 있는 후보들 안에서 우선순위를 적용합니다.
  예: HP 5 용병은 너무 멀고 HP 30 용병은 공격 가능하면 HP 30 용병을 공격합니다.
- **Chase Preferred Target**: 전체 살아 있는 용병 중 우선 대상을 먼저 정합니다. 그 대상을 공격할 수 없으면
  가까운 다른 용병을 공격하는 대신 우선 대상을 향해 이동합니다. 이동 불가·막힌 경로이면 안전하게 턴을 끝냅니다.
  매 턴 다시 고르며 여러 턴 동안 한 명을 고정 추적하는 기능은 아닙니다.

이동 목적지를 정할 때 조준 가능한 위치가 있다면 기존 MoveTendency를 적용합니다.
추격 중에는 우선 대상에게 조준 가능한 위치만 후보에 넣습니다. 그런 위치가 없으면 접근 거리를 줄입니다.

## 특정 스킬만 다르게 설정

스킬 DA의 **AI → Override Enemy Target Policy**를 켜고 **Enemy Target Policy**를 설정합니다.
해당 스킬로 공격할 때만 몬스터 기본 정책 대신 이 설정 전체(우선순위·추격·태그)를 사용합니다.
체크를 끄면 몬스터 설정을 상속합니다. 공유 스킬 DA이므로 이 스킬을 쓰는 모든 몬스터에게 적용됩니다.
플레이어의 조준 UI와 자기 버프(`Spell`)에는 적용되지 않습니다.

예시:

1. 거미 DA: `Lowest HP Percent + Attack Available Target`.
2. 독 스킬 DA: Override 활성화, `Without Status`, Status Tag에 실제 독 효과 태그 지정.
3. 평소 공격은 부상자를 노리고, 독 스킬은 아직 독에 걸리지 않은 용병을 우선합니다.

스킬을 고르는 기존 SkillPriorities / 쿨다운 / AP 로직은 유지합니다.
고른 스킬이 닿지 않더라도 다른 스킬로 바꾸지 않으므로 기존 예상 스킬 표시와 일치합니다.

## 검증

자동화: `P_RD.SRPG.EnemyTargetPriority` 및 기존 `P_RD.SRPG.EnemyTurnPlanner`.
대상 순위, 추격/대체 공격, 속박, 스킬 예외, 태그, 광역 범위, 시드 재현성,
RoomInstance 복제 후 플래너 명령/난수 소비 일치를 확인합니다.
RoomClone 검사는 모델 복제와 플래너 단위 검증이며, 전체 시뮬레이션 애니메이션 재생 검증은 아닙니다.

에디터에서 몬스터별로 정책을 선택한 뒤 실제 전투 난이도는 별도로 플레이하며 조정하세요.

2026-09-17 검증 결과: Win64 Development Editor 빌드 성공, 위 자동화 9개 모두 통과.
기존 몬스터 DA 27개와 참조 스킬을 읽어 기본 정책 및 override 비활성 유지 확인.

실제 거미·독수리·해골새 DA/스킬을 로드한 추가 플래너 테스트도 통과했습니다.
