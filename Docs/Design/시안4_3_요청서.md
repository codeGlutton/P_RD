## 0. 세 줄 요약

1. **장비를 통째로 뺀다.** 무기·장갑·장화 줄이 사라진다
2. **피해는 한 숫자다.** `8~12` 가 아니라 `8`. 크리티컬은 배율이 고정이라 **줄마다 안 적는다**
3. **아티팩트는 용병 것이 아니다.** 파티 전체가 나눠 쓰는 것이라 용병 칸 밖으로 나가야 한다

## 1. 피해와 크리티컬 — 정해졌다

전투 담당(모호재)과 맞춘 결과다. **앞 요청서에 적은 `min ~ max` 는 취소한다.**

| 것 | 정한 것 |
|---|---|
| 피해 폭(min~max) | **없앤다.** 피해는 한 숫자다 |
| 크리티컬 배율 | **고정** |
| 크리티컬 확률 | **고정** |
| 어디서 터지나 | **모든 피해**. 스킬·함정 가리지 않는다 |

### 1.1 그래서 화면이 이렇게 바뀐다

**크리티컬 숫자를 스킬마다 적지 않는다.**

배율도 확률도 고정이고 모든 피해에 똑같이 걸리므로, 스킬 줄에 `크리 18` 을 적으면
**모든 줄에 같은 규칙이 반복되는 것**이라 자리만 먹는다.

```
✕  피해 8~12      크리 18        ← 앞 요청서. 취소
✓  피해 8                        ← 이렇게
```

크리티컬은 **화면에 상시로 안 적는다.** 실제로 터졌을 때 판 위에 뜨는 숫자로만 보여준다
(그건 이번 요청 밖이다).

### 1.2 남은 열린 질문 (그림에 안 그려도 된다)

- 크리티컬 확률을 **용병마다** 두나, 전부 같나
- 직업마다 초기값이 다른가
- 확률을 올려 주는 아티팩트가 있나

**셋 다 안 정해졌다.** 정해지면 용병 창에 한 줄이 붙을 수 있으니 **자리만 비워 두는 게 아니라, 그때 다시 요청한다.**

## 2. 용병 상세창 (기사) — 고칠 것

받은 그림 기준으로.

### 2.1 빼는 것

| 뺄 것 | 왜 |
|---|---|
| **장비 줄 통째로** | 장비를 안 쓰기로 정했다. 무기·장갑·장화 셋 다 |
| 「장비」 제목 띠 | 같이 |

빈 줄로 남기지 마라. **줄이 사라지고 창이 그만큼 짧아진다.**

### 2.2 기술 칸은 여섯이다 — 구조가 정해졌다

| 칸 | 무엇 | 바뀌나 |
|---|---|---|
| 1 | **평타** | ✕ 고정 |
| 2 | **이동** | ✕ 고정 |
| 3~6 | **기술 넷** | ○ 런 중에 얻고 바꾼다 |

지금 기사가 실제로 가진 것은 **다섯**이다. 그러니 **여섯 칸 중 한 칸이 비어 있어야 한다.**

```
[평타]  [이동]  [강타]
[검기 날리기]  [방어]  [ ＋ ]     ← 빈 칸
```

빈 칸은 **점선 테두리 + 흐린 `＋`**. 받은 인벤토리 그림의 그 `＋` 칸이 정확히 맞다. 그걸 여기에도 쓴다.

> 받은 그림은 다섯 칸만 그렸다. **여섯 번째 빈 칸을 넣어 달라** — 칸이 남는다는 것이 보여야
> "기술을 더 얻을 수 있다"가 읽힌다.

### 2.3 행동력 보석

받은 그림은 **열 개를 잘 그렸다. 그대로 간다.**

열한 개부터는 열 개 + `+N`. (앞 요청서 1.4 그대로)

### 2.4 그대로 두는 것

초상·이름·직업 리본·레벨·경험치 막대·한 줄 설명·체력·방어·특성·전투 기록 — **다 좋다.**

## 3. 적 상세창 (늑대인간) — 고칠 것

### 3.1 행동력 보석이 셋이다 → 열로

받은 그림은 `AP ◆◆◆` 세 개다. **열 개로 그려 달라.** 용병과 같은 규칙이다.

### 3.2 피해 표기

`피해 10` / `피해 20` / `피해 35` — **받은 그대로가 맞다.** 폭을 넣지 마라.

### 3.3 그대로 두는 것

정예 뱃지 · 「달려든다」 성향 띠 · 쓰는 기술 세 줄 · 취약 ×1 · 처치 보상 · 도감 번호 — **다 좋다.**

특히 **성향 띠**(붉은 칼 + "달려든다" + 작은 설명)가 잘 나왔다. 이게 이 창의 핵심이다.

## 4. 스킬 상세창 — 고칠 것

### 4.1 빼는 것

| 뺄 것 | 왜 |
|---|---|
| **명중률 95%** | **맞고 빗나가는 개념이 아예 없다** |
| **치명 확률 10%** | 확률이 고정이라 스킬마다 적을 이유가 없다 (1.1) |

`강타` 창 아래쪽의 `⊕ 명중률 95%  ✳ 치명 확률 10%  ★ 강화 ★☆☆` 줄에서
**앞의 둘을 빼고 「강화」만 남긴다.**

### 4.2 피해는 한 숫자

`대상에게 8의 데미지를 입힙니다` — **받은 그대로가 맞다.** 폭·크리를 넣지 마라.

### 4.3 사거리 도해 — 9×9 가 필요하다

**여기가 이번에 가장 크게 바뀐다.**

받은 `연속 찌르기` 그림은 5×5 인데 **직선 3칸이 격자 밖으로 나간다.** 실제로 오른쪽 끝이
잘려 있다.

실제 13개 스킬로 계산했다. `필요 반경 = 사거리 + 효과가 뻗는 칸수`, 격자 = `2×반경+1`:

| 격자 | 스킬 |
|---|---|
| **5×5** | 베기 · 강타 · 대검 베기 · 이동 · 방어 · 명상 · 해골 펀치 · 해골 발차기 · 해골 강펀치 · 짓누르기 **(10개)** |
| **9×9** | 검기 날리기 · 연속 찌르기 |
| 11 필요 | **조준 사격 — 하나뿐** |

#### 정한 것

| 규칙 | 값 |
|---|---|
| 격자 크기 | **5×5 또는 9×9 둘 중 하나.** 중간(7)은 안 쓴다 |
| 고르는 법 | 필요 반경 **2 이하 → 5×5**, 넘으면 **9×9** |
| 도해 전체 폭 | **396px 고정.** 5×5 면 칸 79px, 9×9 면 칸 44px |
| 9를 넘을 때 | 자르고, 잘린 쪽 가장자리에 **화살표와 `+N`** |

**폭을 고정하는 까닭:** 이 창은 효과 줄 수 때문에 이미 세로가 들쭉날쭉하다. 가로까지 흔들리면
스킬마다 다른 물건으로 보인다.

**중간 크기를 안 쓰는 까닭:** 7×7 을 넣으면 칸 크기가 셋이 되고 낱장 스프라이트도 셋이 된다.
실제로 7이 필요한 스킬이 **하나도 없다.**

#### 색 (받은 그림 그대로)

| 것 | 색 |
|---|---|
| 빈 칸 | 어두운 남색, 얇은 테두리 |
| 시전자 | 가운데. **금테** + 말 모양 |
| 닿는 칸 (조준) | **하늘색** |
| 맞는 칸 (효과) | **주황** |
| 잘린 쪽 | 가장자리 칸을 반쯤 흐리게 + `→ +1` |

### 4.4 이번에 그려 줄 스킬 창 셋

| # | 스킬 | 격자 | 보려는 것 |
|---|---|---|---|
| 1 | **강타** | 5×5 (칸 79px) | 짧은 창. 받은 것에서 명중률·치명만 빼면 된다 |
| 2 | **연속 찌르기** | **9×9 (칸 44px)** | 직선 3이 안 잘리고 다 들어간 모습 |
| 3 | **조준 사격** | **9×9, 한 칸 잘림** | 오른쪽 끝에 `→ +1`. **잘림을 어떻게 보여줄지 정하려는 것** |

`조준 사격` 값: 행동력 1 · 쿨다운 0 · 사거리 1 십자 · 범위 **4칸 직선** · 피해 6 · 약화 2중첩

## 5. 인벤토리 화면 — 크게 고친다

받은 그림이 **아티팩트를 기사 칸 안에 넣었다.** 그러면 기사의 아티팩트로 읽힌다.

### 5.1 아티팩트는 파티 전체 것이다

**모든 용병이 나눠 쓴다.** 누구를 골라 보든 **똑같이** 보여야 한다.

그래서 배치를 이렇게 바꿔 달라:

```
┌─ 인벤토리 ─────────── 💰1,240 ── 2층·방4/8 ─┐
│                                              │
│  ┌── 파티 ────────────────────────────────┐ │
│  │  [기사]   궁수    마법사                │ │  ← 탭
│  ├────────────────────────────────────────┤ │
│  │ [초상] 기사 Lv.3    기술 (5/6)          │ │
│  │  ❤100/100          [평타][이동][강타]  │ │
│  │  🛡0  ◆10          [검기][방어][ ＋ ]  │ │
│  │  "앞줄을 막고…"                         │ │
│  └────────────────────────────────────────┘ │
│                                              │
│  ┌── 아티팩트 · 파티 전체가 함께 쓴다 ────┐ │  ← 바깥으로
│  │  ◇낡은숫돌 ◇가죽견갑 ◆은빛종          │ │
│  │  ◆피의성배 ◈시간의모래 ◈심장결정      │ │
│  └────────────────────────────────────────┘ │
└──────────────────────────────────────────────┘
```

**핵심: 아티팩트 영역이 파티 상자 *바깥*에 있어야 한다.**
테두리를 따로 두르고, 제목에 **「파티 전체가 함께 쓴다」** 를 글로 적어 달라.
탭을 바꿔도 이 줄은 안 바뀐다는 것이 눈에 보여야 한다.

### 5.2 빼는 것

- **장비 줄 통째로** (무기·장갑·장화)
- 「장비」 제목 띠

### 5.3 기술 칸

**여섯 칸.** 다섯 차고 하나 빈다. 받은 그림의 `＋` 칸이 정확히 맞다 — 그대로 쓴다.

### 5.4 그대로 두는 것

파티 탭 셋 · 돈 · 층/방 진행 · 초상·체력·방어·행동력 · 아티팩트 툴팁 — **다 좋다.**

**아티팩트 툴팁**(시간의 모래 위에 뜬 작은 창)이 특히 잘 나왔다. 그대로 간다.

## 8. 이번에도 지킬 것

- **빈 홈을 파지 마라.** 값이 없으면 줄을 아예 안 그린다. **단 기술 칸의 `＋` 는 예외** — "더 넣을 수 있다"는 뜻이라 있어야 한다
- 글자는 **넣어서** 그린다
- 판을 억지로 같은 크기로 맞추지 마라. 내용에 따라 세로가 달라지는 것이 맞다
- 반투명 유리·블러 금지. 뒤의 타일맵이 비쳐 글자가 안 읽힌다
- 그림자를 판 바깥으로 흘리지 마라

## 9. 무엇이 왜 바뀌었나

| 앞 요청서 | 이번 | 까닭 |
|---|---|---|
| 피해 `8~12`, 크리 `18` | **피해 `8`, 크리 안 적음** | 배율·확률이 고정이라 줄마다 적으면 같은 말의 반복이다 |
| 장비 3칸 (하나 참, 둘 빔) | **삭제** | 장비를 안 쓰기로 정했다 |
| 기술 5칸 | **6칸 (평타·이동 고정 + 넷)** | 칸 구조가 정해졌다 |
| 아티팩트가 용병 칸 안 | **파티 상자 밖** | 모든 용병이 함께 쓰는 것이라 |
| 명중률 95% | **삭제** | 맞고 빗나가는 개념이 없다 |
| 도해 5×5 | **5×5 / 9×9 두 가지** | 직선 3칸이 5×5 를 넘는다 |

> 이번 것은 **되돌릴 수 있는 결정들이다.** 크리티컬 확률을 용병마다 두기로 하면 용병 창에
> 한 줄이 붙고, 장비를 되살리면 줄이 하나 늘어난다. 그때 다시 요청한다.
