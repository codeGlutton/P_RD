# 시안4_5 요청서 — 턴 순서 판을 여섯 칸 + 양끝 넘김칸으로

> 대상: 이미지 생성 담당 · 요청: 박용수(UI)
> 기준: 지금 게임에 들어가 있는 **턴 순서 판**(`KK_HUD04_top_center_turn_order`).
> 그 판을 **넓히고 칸을 늘려** 다시 그려 달라. 결정 근거는 [`../UI/턴순서_기획.md`](../UI/턴순서_기획.md).

---

## 0. 한 장이면 된다

**조각으로 안 나눠도 된다.** 판 한 장에 칸을 그려 넣는 방식 그대로다 --
지금 판도 그렇게 되어 있고, 게임은 그 위에 초상과 금테두리만 얹는다.

바뀌는 것은 **판이 넓어지고 칸이 다섯에서 여덟(초상 여섯 + 넘김칸 둘)로
늘어나는 것**뿐이다.

---

## 1. 왜 바꾸나

지금 판에는 칸이 **다섯**뿐인데, 한 판에 도는 유닛은 **여섯이 상한**이고
경우에 따라 더 많다.

| | |
|---|---|
| 파티 | 셋 |
| 방 데이터의 적 최대 | 셋 |
| **합** | **여섯** |

여섯째부터는 그릴 자리가 없어 **말없이 잘린다.** 잘렸다는 표시도 없다.

그리고 보스 방에 졸개를 늘리거나 한 적에게 턴을 두 번 주면 일곱, 여덟이
된다. 그때를 위해 **양끝에 넘김칸**을 둔다.

---

## 2. 어떻게 쓰이나

여섯 이하 — 넘김칸 둘 다 **빈칸**.

```
[  ][기사][야만][마법][적1][적2][적3][  ]
```

일곱 — 오른쪽 넘김칸에 **가려진 수**가 뜬다.

```
[  ][기사][야만][마법][적1][적2][적3][+1]
```

그걸 누르면 창이 오른쪽 끝으로 간다. 이제 왼쪽에 하나 가려졌다.

```
[+1][야만][마법][적1][적2][적3][적4][  ]
```

**넘김칸에는 얼굴이 아니라 수가 들어간다.** 그리고 **대부분의 판에서는 비어
있다** -- 여섯 이하면 안 뜬다. 그래서 비어 있어도 판이 어색하지 않아야 한다.

---

## 3. 자리 — 이 값을 지켜 달라

게임이 이 자리에 초상과 글자를 얹는다. **한 픽셀이라도 어긋나면 얼굴이 칸
밖으로 나간다.**

### 3.1 판

| | 지금 | **부탁할 것** |
|---|---|---|
| 판 크기 | 713 × 158 | **819 × 158** |
| 초상 칸 수 | 5 | **6** |
| 초상 칸 크기 | 85 × 85 | **그대로 85 × 85** |
| 초상 칸 간격 | 122.5 | **108** |
| 넘김칸 | 없음 | **양끝에 50 × 55 하나씩** |

**초상 칸 크기는 절대 바꾸지 말아 달라.** 얹을 얼굴 그림과 "지금 차례" 금테두리가
이미 85에 맞춰져 있다. 크기가 바뀌면 그것들을 전부 다시 맞춰야 한다.

칸을 하나 더 넣을 자리는 **간격을 122.5에서 108로 좁혀** 만든다.

### 3.2 칸 자리 (판 왼쪽 위가 원점)

```
end_left          ( 24, 52,  50, 55)     넘김칸 — 수가 들어간다
turn_portrait_01  ( 97, 37,  85, 85)
turn_portrait_02  (205, 37,  85, 85)
turn_portrait_03  (313, 37,  85, 85)
turn_portrait_04  (421, 37,  85, 85)
turn_portrait_05  (529, 37,  85, 85)
turn_portrait_06  (637, 37,  85, 85)
end_right         (745, 52,  50, 55)     넘김칸 — 수가 들어간다
```

세로는 초상 칸이 위에서 37, 넘김칸이 52다. **넘김칸이 초상보다 작고 가운데에
맞춰져 있다.**

---

## 4. 생김새

### 4.1 지금 판을 그대로 이어간다

나뭇결 가로대 · 네 모서리 금속판 · 어두운 안쪽 · 칸마다 나무 액자. **그
분위기를 바꾸지 말아 달라.** 옆에 있는 라운드 판과 메뉴 막대가 같은 결이라
혼자 달라지면 눈에 띈다.

### 4.2 넘김칸은 초상 칸과 **달라 보여야 한다**

얼굴이 들어가는 자리가 아니라 **수가 들어가는 자리**다.

- 초상 칸보다 **작고**, 세로로 가운데
- 액자를 두르지 말고 **안쪽으로 판 홈**처럼
- 색을 죽여서 (어두운 나무나 금속) 얼굴 칸과 구별되게
- **비어 있을 때가 대부분**이다. 비었을 때 "빠진 칸" 이 아니라 "원래 그런
  자리" 로 보여야 한다

### 4.3 넘김칸은 눌린다

버튼이다. **누를 수 있게 생겨야** 한다 -- 살짝 도드라지거나 테두리가 있거나.
다만 얼굴 칸보다 눈에 띄면 안 된다. 주인공은 얼굴이다.

## 5. 납품

```
시안4_5/
├ KK_HUD04_top_center_turn_order.png     819 × 158, 배경 투명
└ coordinates.json                        칸 자리 확인용
```

- **배경 투명 PNG.** 초록 판 위에 그리지 말아 달라. 그리면 걷어 내는 데 한
  단계가 더 든다
- **여백 없이 판 크기 그대로** 819 × 158. 투명한 둘레가 남으면 자리가 어긋난다
- 그림자는 판 **안쪽**에만. 밖으로 흘리면 잘린다

`coordinates.json` 은 3.2 의 값을 그대로 옮겨 적되, **실제로 그린 자리**를
적어 달라. 내가 잰 값과 다르면 그린 쪽이 맞다 -- 그 값으로 게임을 맞춘다.

```json
{
  "canvas": [819, 158],
  "cells": [
    { "id": "end_left",         "rect": [ 24, 52, 50, 55] },
    { "id": "turn_portrait_01", "rect": [ 97, 37, 85, 85] },
    { "id": "turn_portrait_02", "rect": [205, 37, 85, 85] },
    { "id": "turn_portrait_03", "rect": [313, 37, 85, 85] },
    { "id": "turn_portrait_04", "rect": [421, 37, 85, 85] },
    { "id": "turn_portrait_05", "rect": [529, 37, 85, 85] },
    { "id": "turn_portrait_06", "rect": [637, 37, 85, 85] },
    { "id": "end_right",        "rect": [745, 52, 50, 55] }
  ]
}
```

## 6. 넣지 말아 달라

| | 왜 |
|---|---|
| **얼굴** | 게임이 얹는다. 칸은 비워 달라 |
| **`+1` 같은 글자** | 게임이 얹는다. 넘김칸도 비워 달라 |
| **"지금 차례" 금테두리** | 게임이 얹는다 (`KK_HUD04_selected_outline`) |
| **화살표** | 넘김칸에는 화살표가 아니라 수가 들어간다 |

---

## 7. 나중에 따로 부탁할 것 — 지금은 아니다

**라운드 경계 금.** 줄이 고리를 돌기 때문에 어딘가에서 이번 라운드가 끝나고
다음이 시작되는데, 지금 판에는 그 경계가 안 보인다.

칸 사이 어디에나 설 수 있어야 해서 **판에 그려 넣으면 안 되고 낱장**이어야
한다. 넘김칸부터 넣어 보고 헷갈리면 그때 부탁하겠다.
