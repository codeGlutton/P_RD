# 영상 캐시와 전투 화면 처리

이 변경은 영상 파일 처리와 전투 칸의 불필요한 갱신을 줄인다.

- 파일 크기가 같아도 내용이 바뀐 영상은 캐시를 갱신한다.
- 영상 크기를 알아낼 때 파일 전체를 메모리에 읽지 않는다.
- 강조 효과가 켜진 전투 칸만 갱신한다.
- 전투 미리보기의 복제·행동·턴 처리 시간을 측정할 추적 구간을 추가한다.

자동 검사는 MediaCacheTests.cpp와 TileHighlightPulseTests.cpp에서 확인한다.
프레임률과 발열 개선 폭은 기기에서 별도로 측정해야 한다.
이 PR에는 저장 복구, 터치 입력 변경, Android 패키징 도구가 포함되지 않으며
이 작업들을 선행할 필요도 없다.
