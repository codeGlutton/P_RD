SVN UI 에셋 점검 · 분류

잰 자리를 그림 위에 덧그렸다. 아이콘·초상화는 바깥(파란 점선)만 그린다 — 그림 안의 빈 곳은 칸이 아니다. 프레임은 바깥에 더해 구멍을 전부 그린다. 구멍은 하나가 아닐 수 있다(3열 틀은 셋). 칸(주황)은 글자·아이콘을 놓아도 테두리를 안 밟는 자리다. 분홍 선은 9-slice 자를 자리, 없으면 늘리면 안 된다.

실루엣 쓸 수 있는 칸 9-slice 자를 자리

카드를 클릭하면 골라진다(여러 개 가능). 아래 띠에서 분류를 누르거나 숫자키 1·2·3을 누르면 고른 것 전부에 그 분류가 붙는다. 0 은 미분류로, Esc 는 고른 것 풀기. 새로고침해도 남는다.

고른 것 0개 — 분류를 누르면 한 번에 붙는다

글자·아이콘을 놓을 칸을 정한다. 선을 끌면 옮겨지고 손잡이를 끌면 크기가 바뀐다. ← → 로 옆 그림으로 넘어간다(숫자칸에 커서가 있으면 안 넘어간다). Esc 로 닫는다. 가운데 단추는 크기는 그대로 두고 자리만 맞춘다.
