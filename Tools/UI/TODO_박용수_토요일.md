## 0. SVN 업데이트 절차 (데이터셋 맞추기 전에 이것부터)

로컬에서 지운 165개가 SVN엔 삭제 예약이 안 돼 있어, 그냥 update 하면 전부 되살아난다.
**지운 것을 "삭제 예약"으로 바꾼 뒤 update** 하면 안 되돌아온다(예약은 로컬 상태 — 서버에 안 올라감).

```bash
cd /d/UnrealProjects/P_RD_develop_20260803/Content/SVN
svn status | grep '^!' | sed 's/^!\s*//' > /tmp/svn_missing.txt
svn rm --targets /tmp/svn_missing.txt
svn update
```

- 삭제 예약 후 `svn status`에서 `!` 165개가 `D` 로 바뀌어 있어야 한다.
- `A` 55개(새 텍스처)·`?` 90개(PNG 원본)는 update 와 충돌 없음.
- 이후 팀 컨펌이 나면 커밋 한 번에 삭제(D)+추가(A)가 같이 올라간다. **컨펌 전 커밋 금지 그대로.**
- 만약 update 중 tree conflict 가 나면: 지운 파일을 누가 수정한 것 → 그 파일만 `svn revert` 후 살릴지 재결정.
