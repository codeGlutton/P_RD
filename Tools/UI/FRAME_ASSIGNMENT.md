# 화면별 프레임 배정 (측정값 기준)

좌표는 [FRAME_CATALOG.md](FRAME_CATALOG.md) 의 비율을 **1920×1080 으로 환산**한 값이다.
프레임을 먼저 고르고 배치를 나중에 하지 않는다 — 화면에 필요한 칸 수를 정하고,
그 칸을 가진 프레임을 고르고, 칸을 그대로 좌표로 쓴다.

## 배정에서 나온 판단거리 두 가지

**1. 상세 3종과 탭 2종이 같은 프레임을 쓰게 된다.**
다열 전면 판이 `T_MT_BaseFrame` 하나뿐이라 스킬/적 상세·용병탭·몬스터탭이 전부 같은
그림을 깔게 된다. 정보 구조는 실제로 "명단·상세·부가" 3열로 같으므로 **일관성 면에서는
오히려 좋다**. 다만 화면을 넘길 때 배경이 똑같아 어디 있는지 헷갈릴 수 있다.
→ 색 틴트(주황/청록)나 제목 띠 색만 바꿔 구분할지, 상세 전용 3열 프레임을 새로 만들지 선택.

**2. 지도는 프레임이 화면 방향과 안 맞는다.**
`T_StageMap_Background_Parchment` 는 **941×1672 세로형**이다. 지금 5안 전부 이걸
1920×1080 으로 깔아 **가로로 3.2배 늘렸다**. 두 갈래 중 하나를 골라야 한다.
- (A) 세로 스크롤 지도로 설계 — 새 에셋 불필요. 폭 608 띠를 중앙에 두고 위아래 스크롤.
- (B) 가로 지도로 설계 — **가로형 배경을 새로 만들어야 함**.
