## Project Analysis Tools

gdep is a **static project structure analyser** — think of it as a map and
reconnaissance drone for your codebase. It scans source files and engine assets
to tell you *what exists* and *how things connect*, so the AI agent doesn't
have to read every file.

- **What gdep knows:** classes, inheritance hierarchies, dependencies, call graphs,
  Blueprint↔C++ bridges, GAS flows, Animator state machines, engine asset references

- **What gdep does NOT know:** runtime behavior, Blueprint visual-script internals,
  GameplayEffect numerical values, or "why does this crash"

### wiki_search Advanced Usage
```python
# mode='and' — all words must match (use when OR returns too many results)
wiki_search(project_path, "GAS ability zombie", mode="and")
# → returns only nodes containing ALL three terms, not just 'ability' alone

# mode='phrase' — exact phrase in order (strictest match)
wiki_search(project_path, "gameplay ability system", mode="phrase")
# → returns only nodes with this exact phrase sequence

# related=True — expand results via dependency edges (depends_on / inherits / uses_asset)
wiki_search(project_path, "ULyraAbilitySystemComponent", related=True)
# → primary results + all wiki nodes that depend on / inherit from / use this class
# → nodes NOT yet in wiki appear as stubs: '(not yet analyzed)'
#   giving you a map of unexplored relationships to investigate next

# Combine: find classes related to damage system with all terms present
wiki_search(project_path, "damage handler", mode="and", related=True)
```

**When to use each mode:**
| mode | Use when |
|------|----------|
| `or` (default) | Exploring a concept — cast a wide net |
| `and` | OR returns 20+ nodes but most are irrelevant |
| `phrase` | Searching exact method/class names with spaces |

**When to use related=True:**
- You found a central class and want to see everything connected to it
- You suspect related classes exist but don't know their names
- You want to discover unexplored (not-yet-analyzed) edges in the dependency graph
