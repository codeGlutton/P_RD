## CLI Commands (via execute_gdep_cli)

### detect
Auto-detect project type (Unity, UE5, Axmol, C++, .NET, etc.).
| Option | Description |
|--------|-------------|
| --json | Output as JSON |
Example: `["detect", path]`

### scan
Analyze class coupling and detect structural issues.
| Option | Description |
|--------|-------------|
| --circular | Detect circular dependencies |
| --dead-code | Detect unreferenced classes (in-degree 0) |
| --deep | Analyze method bodies for deeper coupling |
| --include-refs | Factor in engine asset refs (prefabs/blueprints) for dead-code filtering |
| --top N | Show top N high-coupling classes (default: 20) |
| --namespace NS | Filter to specific namespace |
| --ignore PATTERN | Exclude file patterns (repeatable) |
| --format | console, json, mermaid, or dot (default: console) |
| --kind | Force project type: unity, dotnet, cpp, unreal |
Example: `["scan", path, "--circular", "--dead-code"]`

### describe
Show class structure: fields, methods, dependencies, asset usages.
| Option | Description |
|--------|-------------|
| --summarize | Prepend AI-generated 3-line role summary (cached) |
| --refresh | Bypass summary cache and regenerate |
| --format | console, mermaid, or dot (default: console) |
| --output FILE | Save output to file |
Example: `["describe", path, "ClassName"]`

### flow
Trace a method's call chain with async/lock/dispatch annotations.
| Option | Description |
|--------|-------------|
| --class CLASS | Entry-point class (required) |
| --method METHOD | Entry-point method (required) |
| --depth N | Tracing depth 1-10 (default: 4) |
| --focus-class CLASSES | Comma-separated classes to trace deeply |
| --format | console, json, mermaid, or dot |
| --output FILE | Save output to file |
| --kind | Force project type |
Example: `["flow", path, "--class", "Foo", "--method", "Bar"]`

### impact
Show change blast radius — who depends on this class, transitively.
| Option | Description |
|--------|-------------|
| --depth N | Reverse-dependency tracing depth (default: 3) |
| --kind | Force project type |
Example: `["impact", path, "ClassName"]`

### method-impact
Reverse-trace all callers of a specific method across the project.
C++ projects use regex-based call graph; C#/Unity projects use Roslyn.
Example: `["method-impact", path, "ClassName", "methodName"]`

### path
Find the shortest call path between two methods (BFS on source-level call graph).
**C#/Unity only** — C++ and UE5 projects are not supported yet.
| Option | Description |
|--------|-------------|
| --from | Source as Class.Method (required) |
| --to | Target as Class.Method (required) |
| --depth N | Max BFS search depth (default: 10) |
Example: `["path", path, "--from", "UIBattle.OnClick", "--to", "ManagerBattle.PlayHand"]`
