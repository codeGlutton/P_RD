상세한 설명

FStage/FRoom, URunPersistData::GetStage(), URoomTransitionSubsystem::PreloadRoomAsync()는 게임 진행에 필요한 원본 데이터와 전환 API를 제공한다. 다만 지도 위젯이 바로 그릴 수 있는 제목, 색상, 선택 가능 여부, 연결선 정보는 따로 정리해야 하므로 이 View DTO를 유지한다.

원본 데이터와 이 구조체의 차이는 다음과 같다.

  • FStage/FRoom: 실제 Stage 구조, 방 타입, 연결 관계, 현재 Run 데이터의 원본이다.
  • FMapRoomView: WBP_FrontendMap이 방 하나를 그릴 때 필요한 제목, 상태, 색상 기준, 클릭 가능 여부, 선 연결 대상 같은 UI 표시용 값이다.

예를 들어 FRoom::mType과 FRoom::mNextRoomColumns는 Stage 데이터에서 오지만, "이 노드를 Ready 색으로 보여줄지", "ENTER 버튼을 켜도 되는지", "시작 지점인지" 같은 값은 GameMode::GetMapRoomViews()가 현재 Run 상태를 보고 계산해서 이 구조체에 담는다.

Widget은 이 값을 보고 노드/선을 배치하고, 클릭 시 mRow/mColumn만 GameMode에 돌려준다. 방 잠금/선택 가능 여부 같은 규칙 판단도 Widget이 직접 하지 않고, GameMode가 이 값으로 내려준다.
