External skill select sound candidates V3
=========================================

All files in this folder are externally sourced audio candidates converted to
48 kHz / 16-bit / stereo WAV for Unreal import. No synthesized replacement
audio was created for this set.

Folder contents:
- S_SkillSelect_ExtV3_*.wav: skill selection candidates
- Original/: copied source files before WAV conversion
