External action sound candidates V2
===================================

All files in this folder are externally sourced audio candidates converted to
48 kHz / 16-bit / stereo WAV for Unreal import. No synthesized replacement
audio was created for this set.

Folder contents:
- S_MapOpen_ExtV2_*.wav: map/open-paper candidates
- S_XPGain_ExtV2_*.wav: XP gain / level-up candidates
- S_SkillSelect_ExtV2_*.wav: skill selection UI candidates
- S_DiceChoose_ExtV2_*.wav: dice selection / tactile dice candidates
- Original/: copied source files before WAV conversion
