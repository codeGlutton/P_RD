47// 이 타입은 캐릭터 선택 화면에 필요한 표시 데이터를 한 곳에 모은다.
48// Widget은 PlayerUnit DataAsset, 해금 규칙, 시작 스탯 계산 방식을 직접 알지 않고
49// FrontendGameMode가 변환해서 내려준 이 값만 화면에 그린다.
50// 현재 타이틀 -> 캐릭터 선택 -> 첫 방 입장 흐름에서는 확정 시 실제 런 생성 API에 넘길
51// PlayerUnit PrimaryAssetId와 안정적인 선택 index가 필요하다. 그래서 이름/역할/설명 같은
52// 표시 값과 런 생성에 필요한 식별자를 같은 View 값으로 내려준다.
53// 중요한 경계는 이렇다.
54// - UI는 WBP에 배치된 WBP_CharacterCard 순서대로 이 배열의 값을 표시한다.
55// - UI는 직업 enum, DataAsset 로드 상태, 시작 HP/골드 계산 방식을 판단하지 않는다.
56// - Confirm 시에도 UI는 mPlayerUnitId만 FrontendGameMode에 다시 넘긴다.
